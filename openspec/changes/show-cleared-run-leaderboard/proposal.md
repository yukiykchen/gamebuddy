## Why

通关记录已经上传并可按角色、进阶和游戏模式查询，但玩家目前没有入口查看这些记录。下一增量应在现有个人数据窗口中提供可打开、可筛选且能清楚处理加载结果的通关榜。

## What Changes

- 在个人数据窗口增加“通关榜”入口，并允许返回现有个人数据视图。
- 通关榜按角色、进阶和游戏模式三个必填条件查询现有 `GET /v1/leaderboard`。
- 榜单按服务端返回顺序展示名次、榜上名称、观察用时和战斗内读档标记，并允许查看该条记录的终局牌组、遗物和事件选择。
- 为首次进入、加载中、无记录、查询失败和重试提供明确状态。
- 桌面端通过受限 IPC 调用共享服务，不把任意 URL 或请求选项暴露给 renderer。

## Non-goals

- 不修改通关上传、通关判定、战斗内/外读档识别、名字默认值或改名规则。
- 不修改 Worker 的榜单查询参数、返回字段、排序、分页或数据表。
- 不做账号登录、反作弊、成绩删除、全局混排或历史名字回填。
- 不加入自动出牌、鼠标控制或任何游戏状态修改能力。

## Capabilities

### New Capabilities

- `cleared-run-leaderboard-view`: 玩家在个人数据窗口按既有三个维度读取并查看已存储的通关记录。

## Impact

影响个人数据页 HTML、渲染状态与样式，preload 的窄 IPC、main 进程的榜单读取客户端和处理器，以及对应 UI、交互、客户端与 Electron smoke 测试；共享 Worker 行为保持不变。
