## Why

主面板和桌宠现在都像同一套深色后台：侧栏堆连接状态、编号导航、本局数字和引擎广告，建议卡是高大的圆角工单。玩家边打边瞟时看不清「这一步做什么」，点开主窗口也像在看监控台，不像杀戮尖塔 2 的搭子。

## What Changes

- 主窗口改成顶栏 HUD + 场景页签 + 中间建议，不再用厚侧栏当仪表盘。
- 文案改成玩家能读的中文（战斗 / 选牌 / 路线），去掉 `01` 编号、全大写英文眉题，以及把元信息用中点串成装饰。
- 桌宠建议卡改成短票券：标题、两三行理由、最多两组要点；长文放到主窗口。
- 视觉分成两种材料：夜石底（窗口铬件）和羊皮纸建议（当前这一步）。营火金只标当前建议和能量，不给每条边描金。
- 四个姿态、气泡短句、关卡关闭、拖拽点开主窗口都保留。

## Non-goals

- 不代打、不点击、不改游戏或存档。
- 不改 Agent 决策、协议和 Mod 采集。
- 不换桌宠角色，不新增第五姿态，不做生涯统计。
- 不把主窗口做成游戏内 HUD 覆盖层。

## Capabilities

### New Capabilities

- `desktop-ui`: 主窗口的信息层级：顶栏本局状态、场景切换、当前建议作为主内容。

### Modified Capabilities

- `pet-overlay`: 建议卡与精英攻略改成短票券，不挡桌宠身体；状态条不再做成浏览器式芯片。

## Impact

- `src/index.html`、`src/styles.css`、`src/renderer.js`：主窗口结构与样式。
- `src/pet.html`、`src/pet.css`、`src/pet.js`：建议卡/攻略卡尺寸与排版。必要时微调 `main.js` 宠物窗口尺寸。
- 不改 `agent/`、`mod/`、Bridge 事件。验证：`npm run test:syntax`，Electron 看战斗/选牌/休息/路线。
