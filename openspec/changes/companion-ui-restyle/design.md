## Context

见 `proposal.md` 的 Why。主窗口是 `src/index.html` + `styles.css` + `renderer.js` 的侧栏仪表盘；桌宠建议卡是 `pet.html` / `pet.css` 里 350px 高的圆角面板。四个姿态、建议数据字段、窗口 IPC 都不变。视觉方向跟 `frontend-design` skill：先定材料，再写 CSS。

## Goals / Non-Goals

**Goals:**

- 主窗口信息层级：HUD → 页签 → 当前建议 → 细节。
- 桌宠建议卡压成短票券，身体始终露在右侧。
- 两套材料（夜石铬件 / 羊皮纸建议）贯穿主窗口和桌宠，而不是两套产品皮肤。

**Non-Goals:**

- 不换框架、不加组件库、不改 Agent JSON。
- 不把桌宠做成完整主窗口缩小版。

## Decisions

### 1. 双材料，而不是整页深色工单

| Token | Hex | 用途 |
| --- | --- | --- |
| Nightstone | `#1A1520` | 窗口底、铬件 |
| Ash | `#2C2633` | 次级面 |
| Parchment | `#E7D7B8` | 当前建议票券 |
| Ink | `#2A2218` | 票券上的字 |
| Ember | `#E8A040` | 只标当前建议和能量 |
| Heart | `#C45C58` | 生命 / 危险 |
| Moss | `#6B8F71` | LIVE / 安全 |

备选：整页羊皮纸。否决：盖在游戏上会糊成一块黄，也太像 skill 里的默认奶油底。羊皮纸只给「这一步」那张票。

### 2. 主窗口结构：拆掉侧栏

```
+--------------------------------------------------+
| 故障机器人  第1幕 7层  71/75  金72         LIVE |
| 战斗   选牌   路线                      刷新     |
+--------------------------------------------------+
| 建议升级火箭飞拳                                 |
| 两到三句理由                                     |
| [回血] [火箭飞拳] [其他可升级]                    |
+--------------------------------------------------+
```

页签用中文，不用 `01`。标题用宋体族（`Songti SC` / `Iowan Old Style`），界面用 `PingFang SC`。不要 Inter、不要字间距拉满的英文眉题。

备选：保留侧栏只换色。否决：用户要的是结构，不是换皮。

### 3. 桌宠票券：短、浅、贴在角色左边

```
+------------------+     (角色)
| 休息处           |      身体
| 升级火箭飞拳     |      围巾
| 三行理由…        |
| 升级 / 留意      |
+------------------+
```

默认高度大约一张横票，理由超三行截断；点票券或点角色打开主窗口看全文。左缘一条 Ember 竖线表示「当前建议」，不要大标题 + 双列卡片 + 页脚元信息叠满。

`main.js` 建议卡窗口宽度可略减，高度随内容，但必须给角色留出原有 214×242 安全区。

### 4. 文案

状态条写「游戏已连接」，不写 `WAIT` / `COMBAT / TURN 07`。气泡继续短句（「建议升级火箭飞拳」），不指路。

## Risks / Trade-offs

- [主窗口习惯侧栏的人要找一圈] → HUD 把原来侧栏数字全放顶上，页签仍是战斗/选牌/路线。
- [票券截断显得信息少] → 主窗口保留全文；票券点一下可打开主窗口。
- [紫黑 + 金接近深色游戏 UI 套件] → 金只用在当前建议和能量；大面积是夜石和一张浅票，不给每个 panel 描金边。

## Migration Plan

只改渲染层 CSS/HTML 结构。回滚还原 `src/index.html`、`src/styles.css`、`src/renderer.js`、`src/pet.*` 和宠物窗口尺寸。

无。截断行数定为三行，不另做「展开」控件，避免桌宠再变回工单。
