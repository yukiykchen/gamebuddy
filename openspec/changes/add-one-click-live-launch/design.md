## Context

真实 Mod 只能在安装了 STS2、.NET 9 与 Godot .NET SDK 的 Windows 环境构建。游戏只在进程启动时扫描 Mod，因此必须在启动游戏前完成复制。Bridge 固定监听 `127.0.0.1:27182`，Replay Bridge 占用该端口时真实 Mod 无法启动。

## Decisions

### 1. 保守的启动顺序

脚本依次验证前提、确认游戏进程未运行、确认端口空闲、调用既有 `mod/GameBuddyBridge/build.ps1`、启动 Electron，最后启动已经确认存在的游戏可执行文件。任一步失败都停止后续步骤。

### 2. 不杀进程、不绕过 Mod 界面

脚本不会关闭正在运行的游戏或端口占用者，也不会修改游戏 Mod 启用设置。遇到这些情况输出可执行的修复说明；首次加载仍由用户在游戏内确认。

### 3. 可定位与可覆盖

默认复用 `STS2_DIR` 和现有三条 Steam 安装候选路径；`-Sts2Dir` 可覆盖。游戏可执行文件只从已验证的游戏根目录内的已知文件名寻找，找不到时失败并列出需要用户补充的路径。

### 4. 桌面端独立运行

桌面端在独立 PowerShell 窗口中通过 `npm start` 运行，关闭游戏不会强制杀掉桌面端，便于检查其自动回到 WAIT 的重连语义。

## Risks / Trade-offs

- 脚本不能保证游戏内 Mod 已被用户启用；这是游戏 UI 状态，必须保留给用户确认。
- 弹幕向量服务未运行时，桌面端仍会使用原创文案回退，因此一键启动不把它作为阻断条件。
