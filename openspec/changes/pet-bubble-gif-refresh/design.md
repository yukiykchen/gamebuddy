## Context

改版前桌宠窗口紧凑态为 214×242，主气泡与底部状态条都处于角色按钮内部；建议卡另占左侧宽度。上传包包含五角色四态透明 GIF 和主题色参考。试用后发现新 GIF 的局部动作太轻，最终保留原有角色 GIF，只采用版式与静态帧适配。

## Decisions

1. 紧凑窗口扩大至约 320×330。主气泡、角色和状态条拥有独立点击区域；顶部气泡与角色视觉连接，但不叠在角色脸上。状态条只显示连接状态、思考时长和模型模式。
2. 建议气泡采用完整一句结论，最多两行；点击它展开现有详细建议卡。展开时右侧保留角色，左侧是已有建议卡；气泡收起避免重复标题。
3. 所有皮肤沿用原有角色 ID、配置入口和 GIF 文件；补充与原 GIF 匹配的静态 poster 字段。姿态动画由已有 Agent 状态驱动。
4. 减少动态效果时使用对应 GIF 的首帧 PNG，不靠 CSS 停止 GIF。优先保留姿态差异；状态灯无需持续动画。
5. 原有 CSS 角色作为素材加载失败时的回退。主气泡与状态条使用统一深色底、角色主题色仅作小面积强调。

## Risks

- 原 GIF 动效需要在桌宠实际显示尺寸下验收；运行时只装载当前皮肤的当前姿态，保留其它皮肤切换能力。
- Electron 透明窗口尺寸变化可能影响拖拽和屏幕边缘定位：沿用现有右下角锚定方式，并在 Windows 实机检查多显示器和 DPI。
