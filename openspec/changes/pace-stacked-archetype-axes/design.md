## Context

见 `proposal.md`。计分集中在 `agent/knowledge/ironclad-archetypes.js`：`saturated(maximum, amount) = maximum * (1 - exp(-1.35 * amount))`，组合分只要对应组存在就按最弱轴释放。自动打击的 `setupMax` 为 10，另外三套为 0，组合主要来自 `synergies`。侧栏由 `src/archetype-ui.js` 渲染，样式在 `src/styles.css`；候选影响对象已经带有 `beforeScore` 和 `deltaPoints`。

## Goals / Non-Goals

**Goals:**

- 只改变叠卡轴的饱和速度，以及含这些轴的组合释放比例。
- 让起手牌组上的剑柄打击、地狱狂徒和第二张循环件落到规格里的区间。
- 用现有奶油、琥珀和深色面板语言做一块静态铜铁流派框。

**Non-Goals:**

- 不改矩阵权重、角色和原因文案。
- 不把弹药轴放慢。打击的单卡权重已经是 0.45，五张起手打击本来就是一包弹药。
- 不改协议字段，也不把 `beforeScore + deltaPoints` 显示成加入后分数。

## Decisions

### 1. 叠卡轴用更慢的饱和系数，单卡槽保持 1.35

叠卡轴：`auto_loop`、`exhaust_outlet`、`exhaust_event`、`strength_multihit`、`block_source`。这些轴的饱和系数用 `0.45`，一份权重大约吃掉轴上限的 36%，两份大约 59%。

单卡槽保持 `1.35`：`auto_gate`、`auto_payoff`、`auto_ammo`、`exhaust_pain`、`exhaust_draw`、`exhaust_payoff`、`strength_source`、`strength_balance`、`block_gate`、`block_conversion`，以及全部外围辅助轴。地狱狂徒、完美打击、无惧疼痛、黑暗之拥、点燃、恶魔形态、壁垒和全身撞击仍是「第一张完成该槽」。

曾考虑全局把 1.35 改成 0.45。那样第二张地狱狂徒也会变响，和「闸门一张就位」相反，所以系数按轴分开。

### 2. 组合分按叠卡满度缩放，目标满度为 2

组权重累计除以 `2`，上限为 1，得到满度。`setup` 和每一条 `synergy` 只要包含叠卡轴，就乘以其中叠卡轴满度的最小值。不含叠卡轴的组合保持原样。

因此一张剑柄打击在已有地狱狂徒时只释放大约一半循环组合；剑柄加劫掠才接近给满。第二张地狱狂徒不加满度，只增加抽到闸门的可靠性，增量保持很小。

### 3. 面板沿用现有色板，不做新素材

`renderOverview` 改成带标题、状态和四行分数的铜铁块：底 `#241c16`，边 `#6e4b2a`，标题下一条 `#c47a3a` 实线。条形高 4px，普通填充 `#a56b3c`，领先填充 `#e0a15a`。标题用现有 Georgia，不引入图标、火焰或动画。

候选行格式为 `名称 当前% +变化` 或 `名称 当前% -变化`，当前值取 `beforeScore`，变化取 `deltaPoints`。上升用琥珀，下降用 `#c48474`。

## Risks / Trade-offs

- **[风险] 无闸门的多段和格挡来源绝对分变低** → 现有「缺闸门仍大于 20」一类断言改成「大于零且第二份仍达到第一份的 45%」，不恢复硬上限。
- **[风险] 慢曲线让首个潜在组件四舍五入成 0** → 保留现有「首个直接正向组件至少显示 +1」的保底。
- **[风险] 铜铁面板和侧栏其他统计块脱节** → 只换流派块和候选行，牌组厚度等统计保持原样。

## Migration Plan

1. 先把规格区间写成失败测试。
2. 给叠卡轴加慢饱和和满度缩放，再跑四套回归。
3. 改面板标记和样式，用 UI 测试锁定「42% +3」这类文本。
4. 回滚时去掉轴系数和满度乘法，矩阵与协议不变。
