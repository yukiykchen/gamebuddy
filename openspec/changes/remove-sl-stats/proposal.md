# Why

SL 次数无法从当前只读状态稳定区分“玩家读档”和“Bridge 重连”，容易产生误计数。该数字也不参与选牌、路线、休息处或遭遇攻略决策，因此移除整条统计链路，减少干扰和持久化状态。

# What Changes

- 删除本局 SL 的检测、累计和本地持久化。
- 删除主进程 IPC、Observation 附加字段和 preload 订阅。
- 删除主面板数字、桌宠状态数字及相关台词。
- 删除专用验证脚本，并清理仍要求展示 SL 的旧 UI 规格。

# Non-goals

- 不修改游戏存档或 Bridge 的其他状态采集。
- 不影响桌宠四态、选牌、路线、休息处和遭遇攻略。
