## Why

休息处建议目前把完整理由塞进桌宠头顶气泡，长文本会挡住角色。选牌已经用左侧建议卡展示标题、理由、要点和来源。休息处应使用同一套建议卡，气泡只留一句短提示。

## What Changes

- 休息处建议打开与选牌相同的左侧建议卡：标题、理由、要点、来源/置信度，可关闭。
- 气泡只说短句，例如「建议升级火箭飞拳」，不再贴全文，也不提示「理由在左边」。
- 建议卡出现时桌宠进入 `advising`；关闭建议卡后恢复旁观或等待。
- 离开休息处、进入战斗或打开地图时收起建议卡。

## Non-goals

- 不代打、不点击火堆选项。
- 不改变休息处规则或 LLM 决策。
- 不把路线、事件也改成建议卡。
- 不新增第五种桌宠姿态。

## Capabilities

### New Capabilities

- （无）

### Modified Capabilities

- `pet-overlay`: 休息处建议改走选牌同款建议卡，不再用长气泡正文。

## Impact

- `main.js`：休息处 recommendation 也推送到建议卡通道并扩大桌宠窗口。
- `src/pet.js` / `src/pet.html`：建议卡支持 `rest_site`。
- 验证：`npm run test:syntax`；Demo 或真机打开休息处，确认建议卡而不是长气泡。
