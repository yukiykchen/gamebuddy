## Why

当前只实现了自动打击流派度，且规则只显式覆盖部分铁甲卡牌；已有硬毒表还把“主动使用可能误操作”误判成“持有即破坏”。玩家需要用统一口径比较自动打击、消耗引擎、力量叠加、格挡壁垒四套构筑，并确保铁甲完整 87 张卡在每套中都有可解释的作用。

## What Changes

- 建立覆盖全部 87 张铁甲卡牌的“四流派评价矩阵”，每张牌在每套中均归为闸门、核心、输出/资源、辅助、条件、稀释、软反或硬毒。
- 分别计算四套 0–100 流派度与候选牌加入前后的增量；流派度表示构筑完整度/稳定度，不表示胜率。
- 每套使用独立闸门、饱和递减、牌组厚度稀释、升级与相关遗物；共享牌按当前流派语义独立评分。
- 区分“持有反协同”与“主动误用风险”，纠正自动打击现有无卡面依据的固定硬毒。
- 采用 C 型展示：选牌侧栏展示四套当前流派度并标主流派；每张候选最多展示两条显著流派增量及原因。
- 增加完整卡池覆盖测试、四套结构测试与 UI 渲染验证。

## Capabilities

### New Capabilities

- `ironclad-archetype-inclination`: 定义铁甲四流派的完整卡池分类、评分、增量和解释语义。
- `desktop-ui`: 定义侧栏四流派总览及候选牌最多两条显著增量的 C 型展示。

### Modified Capabilities

（无）

## Impact

- `agent/knowledge/`：以声明式规则矩阵替换自动打击单文件白/黑名单。
- `agent/tasks/card-reward.js`、奖励草稿消息：输出四套当前分数与候选增量。
- `src/renderer.js`、`src/styles.css`：新增四流派侧栏和候选显著增量展示。
- `agent/tests/`、Harness：覆盖 87×4 分类完整性、闸门、递减、稀释与渲染。
- 文档：形成可审阅的 87 张铁甲卡牌四流派矩阵。

## Non-goals

- 不把流派度解释为胜率或替换原有选牌推荐排序。
- 不支持铁甲以外角色或第四套之外的其他铁甲流派。
- 不自动点击、出牌或修改任何游戏状态。
