## Context

见 `proposal.md`。个人数据页目前没有玩家名字。通关上传的允许字段里没有显示名，测试还明确排除了 `playerName`。共享服务的 `clears` 表也没有这两列。

## Goals / Non-Goals

**Goals:**

- 本机保存可选显示名。
- 上传时带上显示名和本机玩家编号。
- 榜单结果能读回这两个字段。

**Non-Goals:**

- 不把显示名当作唯一身份或登录凭证。
- 不回溯修改已经上传的记录。

## Decisions

1. 显示名保存在桌面端 `userData` 的偏好文件，和个人复盘数据分开。最长 16 个字符，去掉首尾空白和控制字符。空值一律存成「匿名人士」，输入框不能保持空白。
2. 第一次需要上传时生成 `playerId`（随机 UUID），之后一直用同一个。它不出现在个人数据页。
3. 上传字段名用 `displayName`。没有有效名字时客户端就写成 `匿名人士`，服务端再挡一次空值。
4. `clears` 表增加 `display_name` 和 `player_id`。`runId` 仍是去重主键。排行榜排序不变。
5. 改名只影响之后的新通关。旧记录保留提交时的名字。

## Risks / Trade-offs

- [同名或大量匿名人士无法区分真人] → 用隐藏的 `playerId` 认出同一安装，榜上仍按玩家填写的名字显示。
- [名字可伪造] → 和现有成绩一样，只作为趣味榜标签。
