## Context

现有评分器把四套卡牌映射为结构轴，但条件因子和硬上限主要回答“当前能否运转”。例如 `auto_gate_active` 在无地狱狂徒时为 0，多段攻击在无力量源时仅有极低条件因子，消耗和格挡也受闸门上限压制。候选增量又使用已取整总分相减，因此真实的小幅进展可能显示为 0。

## Goals / Non-Goals

**Goals:**

- 让四套分数统一表达蓝图完成度，而非即时可运行程度。
- 让直接结构组件在闸门缺失时积累潜在进度，并在闸门到位后获得协同放大。
- 分离完成度数值与 started/mature 状态，避免一个布尔闸门同时控制两种语义。
- 保证首个有效结构组件的显示增量可见，同时保留饱和和净负结果。

**Non-Goals:**

- 不使用历史胜率重新拟合权重。
- 不改变 87×4 矩阵“每张牌必须显式评价”的结构。
- 不把所有显式角色强制变成正分；软反、硬毒和净稀释仍可为负。

## Decisions

### 1. 每套拆成基础轴覆盖、闸门覆盖和跨轴协同

总完成度由三部分组成：

```text
progress = baseAxisCoverage + gateCoverage + synergyCompletion
           + relevantRelics - antiSynergy - dilution
```

基础轴覆盖独立计算并饱和递减；闸门是高权重轴；协同完成只在相关轴同时存在时出现。相比“缺闸门统一 cap”，这能保留已经收集到的拼图，同时让完整组合明显高于零散组件。

### 2. 条件组件使用潜在因子，不使用零因子

直接结构组件在缺少使能轴时使用统一的低额潜在因子，存在使能轴时使用完整因子：

- 自动打击弹药：无地狱狂徒低额，有闸门完整。
- 消耗出口/事件/兑现：无收益闸门低额，单/双闸门逐级提高。
- 力量多段：无力量源低额，有来源完整。
- 格挡来源/转伤：缺积累闸门低额，轴齐备后完整。

外围辅助采用更低因子，并要求至少存在一个直接结构轴才能获得主要贡献。这样挑衅、通用抽牌或能量不会在空白牌组中压过直接组件。

### 3. 硬上限只用于状态保护，不截断已获得的蓝图进度

移除“缺闸门最高 10/20”等对完成度总分的硬截断。`started` 和 `mature` 改为同时检查分数阈值与必要轴；缺关键轴时即使积累了多个潜在组件，也只能显示未启动或未成熟。这样数值回答“收集了多少”，状态回答“是否能运转”。

### 4. 候选增量使用原始浮点差再显示

评分器保留内部未取整完成度，候选使用 `rawAfter - rawBefore`。显示时正常四舍五入；若候选是首个直接正向结构组件、净差大于零且四舍五入为 0，则提升到 `+1`。重复饱和、稀释抵消或净差不正不触发保底。

### 5. 用跨四套固定牌组约束相对关系

测试不只断言绝对区间，还断言关键排序：

- 无地狱狂徒时，双重打击 `> 0` 且不低于挑衅。
- 无双收益闸门时，首个消耗出口 `> 0`，补闸门产生额外协同。
- 无力量源时，首个多段攻击 `> 0`，有力量源时增量更高。
- 无格挡闸门时，首个格挡来源/转伤 `> 0`，轴齐备后整体显著上升。

相对关系比绑定任意单个百分比更能防止后续权重校准破坏语义。

## Risks / Trade-offs

- **[风险] 无闸门时分数比旧版高，用户误以为已成型** → started/mature 同时检查必要轴，并在原因中区分潜在组件。
- **[风险] 多个潜在组件可能堆出过高分** → 基础轴使用较低潜在因子、组内饱和，协同分只在轴齐备时释放。
- **[风险] `+1` 保底掩盖微小稀释** → 仅对首个直接组件且原始净差严格为正时生效。
- **[风险] 四套共享辅助重新失衡** → 增加直接组件与外围辅助的排序回归，而不是仅验证正负。

## Migration Plan

1. 先加入四套固定牌组的失败测试，锁定蓝图完成度语义。
2. 重构内部原始分、基础轴、闸门和协同计算，再调整 started/mature。
3. 校准外围辅助、潜在因子和稀释，使四套相对断言同时成立。
4. 运行完整矩阵、兼容门面、Harness 和 OpenSpec 校验。
5. 若需回滚，可恢复旧条件因子与 cap；矩阵和协议结构不变。
