# 本局复盘：本地实现与验证记录

日期：2026-10-26。实现基于本地 `integrate/latest-danmaku-archetype` 的 `dfcd0e8`，接入用户提交的 `5af35a2` 补丁后修改。未提交 Git、未发布安装包、未部署服务。补丁自带的 `run-highlight-recap/` 目录保留作参考，本目录是执行计划。

## 已实现的主流程

个人数据单局展开后展示“本局复盘”：四个固定位置（最高回合实际爆发、最高斩杀、实际抗伤、SL次数）、目标三个重要片段、一句总结。证据不足允许更少。原历史列表、终局牌组和遗物查看保留，不自动弹窗，不增加战斗时间线或回放。

先通过窄 IPC 返回本地可信数字/短卡，再异步生成；只替换复盘区域，不重建整个页面。模型提交失败时保留本地结果。重新打开读取缓存；暂时故障可以重试。事实、快照、覆盖、模型配置、提示、工具和知识版本参与缓存身份；清空和较新事实会使旧任务失效。

模型先看整局分页概览、全局极值线索和已证明的本地片段，再通过六个只读工具取证。每次请求携带工具参数合同及累计查询结果，读预算10次、最多5次取证响应、一次修复，总预算90秒。候选可使用自选类型和短文案，要求结构化断言和名称/数字绑定；不限定六个故事模板。候选经程序检查和模型语义复核后去重，再补入不重复的可信本地片段，最多三张。总结请求只接收最终片段，避免把未选中的查证内容混入总结。

程序检查包括篇幅、完整证据、对象身份、未知字段、数字绑定、布尔值/工程ID误入文案、假零次、普通升级后失败、出牌次数冒充命中/贡献、强反事实等。语义复核是补充筛查，不等同因果证明或人工验收。

## 采集接线与实际边界

| 内容 | 当前实现 | 未验收部分 |
| --- | --- | --- |
| 卡牌/实体身份 | 外部弱引用对象身份；永久牌与战斗副本分开；只接受实际对象引用的来源关系；同名不合并 | 目标游戏版本是否提供可靠 DeckVersion 等对象关系、跨读档身份恢复 |
| 决策现场 | 火堆/奖励/路线/事件/商店的前置快照与结果引用；火堆结果关联同一 decisionId | 所有选项的真实可用规则、随机事件完整结算和嵌套触发 |
| 回合与动作 | 回合开始、BeforeTurnEnd、BeforeCardPlayed（存在时）、出牌/移动/受击/战斗结束观察 | Hook 的实际异步时点；缺 Before Hook 不制造“动作前”状态 |
| 持久化 | `context.snapshot` 嵌入同一持久事实流，经原落盘/ACK保护；兼容旧UI状态快照 | 真机断线/队列拥塞与实际游戏过程的端到端验证 |
| 费用与可用性 | 读取动态费用、抽牌时能量、可读的运行时布尔可用性；可用性缺失保持未知 | 目标/星费/特殊免费打出等完整合法性；费用足够不等于能打 |
| 伤害 | 独立命中观察ID、来源/目标实例、阵营、阶段、显式 HpLoss/Blocked/Fatal 等字段 | 各版本 DamageResult 的真实字段语义与多段/重载；未核实的 uncapped 结算不能拿 requested 顶替 |
| 护盾 | 固定项累计确认的被吸收量；获得/持有格挡另作查询线索 | 游戏真实 blocked 字段的语义及特殊伤害类别 |
| SL | 游戏确认观察的单局元事件；去重且不随有效尝试替换丢失 | Windows 真机多次重载与进程重启的对照 |

无法读取的字段显式未知。快照的 `settlementStatus=hook_observed`，不冒充所有异步效果已经结算。`resolvedDamageBeforeHpCap` / `targetHpBefore` 只接受明确的运行时字段；当前没有游戏 DLL 可核实，故不能承诺真机一定能显示最高斩杀/过量。旧日志无法补回这些事实，指标会保留位置显示“未记录”。

已有存储仍按原语义淘汰被替换的战斗尝试文件，只保留有效战绩与独立SL观察；完整历史尝试归档尚未做。未提供反事实模拟器，不能发布“本来能赢”“必胜”“确定操作失误”等结论。

## 模型试跑与发布门槛

使用当前配置的 `deepseek-flash`，对“升级未上手”和“确认过量命中”两份合成对局做了实际 API 试跑，另保留迭代过程的报告。试跑暴露了嵌套断言格式错误、绑定索引错位、出牌数冒充命中、名称臆造、把true写成次数、总结引入未选片段等问题；已加入对应程序约束/回归测试。

最近一轮远程试跑报告为 `.runtime/recap-evals/recap-eval-model-release-check.json`（recap-6），其中仍发现名称被绑定成次数、未绑定中文数值和把状态终值写成增长等问题。最终recap-7加入类型/单位检查及对应硬约束，保存实际模型候选为 `harness/fixtures/recap-evals/model-response-regressions.json`；固定响应回归验证即使语义复核全部批准，也不会发布这些已知错误，而保留本地可信片段。最终约束后未再次远程评测，因此不将旧报告当作最终版模型效果通过。硬检查通过不表示所有文案语义都已证明；少量模型试跑不能替代20–30局真实数据与玩家盲评。最终候选不足三张时，按证据不足处理，不用普通经过凑数。
