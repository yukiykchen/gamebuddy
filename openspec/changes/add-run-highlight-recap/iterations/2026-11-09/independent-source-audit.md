## 通用不可恢复字段与评测建议

1. card.drawn payload={}，不能讲某牌从没上手/来晚/费用不足。
2. cardInstanceId常为CARD.模型ID，不能区分同名副本，更不能把模板升级连到永久牌。
3. damage缺sourceEntityId/sourceSide/targetSide/fatal/targetHpBefore/resolvedDamageBeforeHpCap/actionId。固定最高回合实际爆发、最高斩杀、实际抗伤不要拿旧summary.maxTurnDamage或entityId=0假定阵营填充。
4. turn.started/ended payload={}，没有可靠player/enemy阶段与turn编号；不要把每个turn事件当一个玩家回合。
5. 无context.snapshot/run.reload_observed；run.observed仍含可靠生命/背包/牌组/遗物观察，可用于观察之间的确定关系，不应被“没新快照”整体丢弃。
6. combat.ended.victory=false及rest.amount=0是已观察到的默认值风险，不只缺失字段。旧quality.unknownFields=[]不表示这些值已经游戏语义核实。
7. 当前四局用于开发/回归，不足以称留出集、真实玩家验收或泛化优秀。对已知样本反复改进属于训练样本优化，应单独标记。
