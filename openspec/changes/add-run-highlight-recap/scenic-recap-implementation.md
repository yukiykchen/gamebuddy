## Changes

- 个人数据展开单局后展示暗色战报：本局画像、角色/进阶/幕内位置/总层数/结果、记录覆盖时长、四项累计数字、已记录选择、次级已知纪录、约三个片段与总结。
- 新增纯投影 `review/recap/presentation.js`：累计有效输出、格挡实际吸收、敌人造成的受伤、实际恢复。未知方向、范围缺口、治疗只有请求量时保持未知；自伤、敌人自损、过量和过量治疗不混入对应数字。
- 新增 `review/recap/choice-relations.js`：按选项、选择和现场组织火堆取舍及跨事件资源风格；精灵保留回扣后续救命需要持有/消失、同战斗归零恢复、30%机制吻合及使用观察共同支持。该项明确标记 `mechanism_correlated`，不伪称有直接药水来源ID或跨读档实例证明。
- 本地短卡从实际关系生成，没有按真实 runId 写死文案。优先以更完整的精灵/选择关系替换重复的普通恢复和上限增长卡，增长值仍保留在已记录选择中。
- 模型取证和总结接入“损友兼战地记者”语气；自由选材、字段绑定、语义复核和失败回退继续存在。提示/工具版本为 recap-13 / recap-tools-8，缓存包含战况摘要，修正楼层后不会误用旧摘要。
- 预览与完成IPC仅传展示字段；后台生成不重建整页，重新展开读取缓存；原历史、终局牌组及遗物仍可查看。展开后取消历史列表的短高度限制，避免战报被挤在小滚动区。
- 背景通过内置 imagegen 生成并复制至 `src/assets/recap/spire-campfire-v1.png`，素材及提示词见同目录 README。画面为高塔、篝火与精灵瓶，无在线图片依赖。
