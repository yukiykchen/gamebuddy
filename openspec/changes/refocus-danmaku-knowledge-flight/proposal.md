## Why

战斗弹幕现在把效果写进飞过的句子，悬停又摊开整页循环；陪看句占画面；字大、飞得快，还没出屏就被定时清掉。玩家要的是短报名、悬停看知识和效果，并停住整场阅读。

## What Changes

- 招式正文改成 `小啃兽即将哈气`。效果写在悬停，例如 `本场战斗力量+2`，不再把效果和百科写进飞过的字。
- 入场仍飞怪物名。悬停最多三行：循环、目标优先级、一条机制要点。不写遭遇列表和每招伤害。
- 入场可多一条知识事实（优先处理谁），只复述 Codex / 遭遇攻略 / 机制标签里已有的结论，不编造出牌。
- 去掉「小伙伴」「陪你」「观战席」等主持句。氛围只保留 B 站原句和短反应 LLM；失败就空着。
- 字号和留白缩小；飞行按屏宽算时间，更慢；只有飞出左缘才卸掉。新波次不清还在飞的。
- 悬停任意一条时，场上所有弹幕一起暂停，离开后一起继续。

## Non-goals

- 不自动出牌、不点击、不改游戏状态。
- 不把完整遭遇攻略或建议面板搬到弹幕正文。
- 不报游戏 UI 已有的血量、格挡、回合数。
- 不从 B 站或 LLM 推断机制或胜率。
- 不重做覆盖层窗口本身。

## Capabilities

### New Capabilities

- （无）

### Modified Capabilities

- `battle-danmaku`: 短报名正文；入场可出一条目标优先级；去掉陪看氛围。
- `scene-language-danmaku`: 悬停只写当前效果/时长和少量知识，不再复述正文或摊开百科。
- `global-danmaku-overlay`: 更小更慢、飞出才消失；悬停一条则全场暂停。

## Impact

- `agent/danmaku/`、`src/danmaku.js`、`src/danmaku.css`、`main.js` 弹幕清屏计时、相关测试
- 复用已有 Codex 与 `encounter-guide` / `encounter-strategies` 的优先级，不新增 Mod 字段
