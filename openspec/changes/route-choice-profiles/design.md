# Design

对每条真实可达路径同时计算安全、平衡和成长三个启发式分数，包含房间收益、风险、有限距离的节点顺序收益、后续调整空间和连续战斗压力。休息处的回血与升级互斥，因此只取二者估计收益的较大值，不能相加。生命 ≥65% 以成长分排序，35%～65% 以平衡分排序，≤35% 以安全分排序；精英数量仅作为展示统计，不作为最高优先级排序键。对同一下一节点取当前视角得分最高的后续路线，然后再比较不同入口。

LLM 只收到去重后的当前入口，附三个视角分数、生命档位、生命/金币、房间统计、路线灵活性、连续战斗压力、有限距离顺序信号及完整路径。模型不能发明节点，危险血量时也不能用缺少依据的乐观推测覆盖明显更安全的入口。

推荐结构新增 `routeProfiles`，分别说明安全、平衡、成长视角的最佳入口，并显示与当前推荐的关系。主面板和桌宠展示三种视角；如果三者同入口，说明共识。分数只作相对比较，不作为胜率或伤害预测。分数与可见节点组成接近时，用 `uncertainty` 标记信息不足，仍提供暂时首选并降低置信度，不再输出“等价任选”。

路线列表仍最多使用已有上限；若 `routesTruncated`，理由和置信度须提示不完整。现有 `map_route` 任务触发和取消时机保持不变。
