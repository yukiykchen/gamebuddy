# Why

当前路线排序先比较精英数量，低生命时风险扣分仍可能被忽略；模型候选按完整路径截取，多个路径共用一个入口时会漏掉其他可选入口。桌宠只报下一节点，没有解释安全与收益的取舍。

# What Changes

- 参考 Route Suggest 的安全/激进视角和节点顺序奖励，但扩展为安全、平衡、成长三档；生命 ≥65% 采用成长、35%～65% 采用平衡、≤35% 采用安全。
- 每个当前可选入口只给一条最优后续路线；LLM 收到全部不同入口，而非重复路径。
- 仅对相邻或隔一层的火堆/宝箱与精英组合加有限加分，并明确评分是启发式而非伤害预测。
- 在主面板和桌宠展示三种视角及主要取舍；可见证据接近时保留暂时首选、降低置信度，不宣称路线客观等价。
- 保持仅在当前分叉分析，不改变只读 Mod、战斗中不推演、单一路径不推演的现有约束。

# Non-goals

- 不引入 Route Suggest 的代码或静态权重原样复制，不自动点击地图。
- 不恢复伤害计算，不依赖此前暂缓的 beta 数据升级。
