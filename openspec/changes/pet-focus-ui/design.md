## Context

现有建议卡将所有内容同时显示，并使用两列嵌套卡片。推荐结论、解释和元数据处于近似视觉权重。透明 Electron 窗口在建议出现后固定增高到 340px，即使玩家只想看结论，也会占用较大的游戏交互区域。

## Information hierarchy

建议卡拆成两层：

1. **即时结论**：任务标识、任务类型和单行选择。选牌用“拿「卡名」”，路线用“走具体入口”，火堆用“在火堆回血”或“升级「卡名」”，事件用“选择「选项」”。
2. **按需解释**：判断依据、收益、风险、备选、策略对照、来源和置信度。

详情默认隐藏。每次收到新建议都恢复收起状态，避免沿用上一条建议的展开偏好。

## Window lifecycle

渲染进程通过 `set-card-expanded` 通知主进程：

- 收起建议：窗口尺寸为 570 x 252；
- 展开建议：窗口尺寸为 570 x 420；
- 攻略可见：继续使用 570 x 520；
- 无建议：恢复 214 x 242。

主进程只在仍有活动建议且攻略未覆盖时接受展开状态。

## Visual system

- 卡片使用单一深色主题和珊瑚色强调，不使用渐变、发光或多色内容块。
- 卡片圆角统一为 16px，交互按钮使用圆形或胶囊形。
- 详情使用留白和单线分隔，不再套两列小卡片。
- 动效只表达出现和展开状态，且遵循 `prefers-reduced-motion`。
- 标题单行截断，确保结论区稳定且不挤压关闭按钮。

## Accessibility

- 展开按钮使用 `aria-expanded` 和 `aria-controls`。
- 键盘焦点使用清晰的强调色描边。
- 按钮文字与背景保持高对比度。
- 详情的 `hidden` 状态同时对视觉和辅助技术生效。

## Design pre-flight

- 已声明设计判断、三档参数和 preserve redesign 模式。
- 主题锁定为暗色；建议卡和攻略只使用一个珊瑚色强调。
- 卡片使用统一 16px 圆角，圆形关闭按钮和胶囊形恢复按钮属于明确的控件规则。
- 默认结论不换行；展开和关闭按钮文字不会在桌宠宽度内换行。
- 可见静态文案不包含 em dash，不使用渐变、外发光、装饰状态点或嵌套卡片网格。
- 出现与展开动画只使用 transform 和 opacity，并提供 reduced-motion 回退。
- 没有新增第三方依赖、图片或 SVG；营销页、表单、导航、响应式页面和 SEO 检查不适用于此固定尺寸 Electron overlay。
