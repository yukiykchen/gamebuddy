## Why

当前弹幕主要按宽泛触发标签检索，导致不同职业、敌人和战斗状态容易得到相似的泛化短句。需要在不让弹幕参与策略的前提下，让它能体现职业氛围、怪物事实和社区化表达。

## What Changes

- 新增职业、房间、敌人、意图、生命状态和显式事件组成的只读场景语言档案；职业字段直接来自 Mod `run.character`。
- 将 Mod 的怪物 ID 连接到已有 Codex，提取已知的怪物行动/机制信息并转写为自然中文弹幕；玩家界面不显示“档案”“标签”“资料”等内部来源词。
- 将宽泛 trigger 扩展为可解释的场景标签和语气标签，例如攻击意图、危险血线、强化、召唤、复活、阶段变化、胜利与结束。
- 新增版本化的特色短句包，为各职业和场景提供原创、非策略性的社区口吻；B 站语料继续提供可追溯氛围表达。
- 调整选句排序、去重和波次构成；普通显著触发生成 6–8 条高密度波次，优先事实关键词，再使用与职业/场景/语气兼容的短句。
- 扩充离线语料标注，保留并使用职业/语气/梗类别 metadata；使用已配置的 LLM 异步生成受严格约束的随机氛围短句，绝不生成或判断策略。

## Non-goals

- 不生成出牌建议、伤害/格挡/胜率预测、职业强弱结论或玩家性格判断。
- 不把 B 站文本当作游戏机制知识，不控制游戏，也不改变 Mod 协议。
- 不让 LLM 调用阻塞、抑制或改变 Mod 事实弹幕；Ollama 仍只用于 embedding。

## Capabilities

### New Capabilities

- `scene-language-danmaku`: 基于只读职业与场景事实，选择多样、可追溯且非策略性的弹幕语言。

### Modified Capabilities

- 无。

## Impact

- `agent/danmaku/scene-context.js`、`catalog.js`、`director.js`、`retrieval.js`、新增 LLM 氛围生成模块、现有 LLM 客户端和离线准备/索引脚本。
- 新增职业语言包和测试，更新独立 Chroma metadata/schema 与重建流程。
- `src/danmaku.*` 仅在需要显示来源或语气样式时调整，不改变鼠标穿透或窗口职责。
