# 复盘高光与最高回合伤害测试方案

## 1. 测试内容

本次只测试最新提交中的两项改动：

- 复盘主数字条第四项改为“本回合最高出伤”。
- 复盘故事先检查数字和文案，再按趣味分决定是否展示；低分故事只重写一次。

## 2. 主数字条

### 已知最高出伤

- 准备最高回合出伤为 50 的对局。
- 打开本局复盘。
- 第四项应显示“本回合最高出伤 50”。
- 下方其他纪录中不应再次显示同一个 50。
- 页面不再显示“实际恢复”。

### 不知道最高出伤

- 准备缺少完整回合伤害记录的对局。
- 第四项应显示“未记录”。
- 不应显示为 0，也不能拿治疗量或单次攻击伤害代替。

### 原有三项

- 检查前三项仍按原顺序显示：
  1. 累计输出
  2. 实际抗伤
  3. 累计受伤
- 三项原有数值不能因本次改动发生变化。

## 3. 复盘故事检查

### 数字正确

- 故事中的数字与对局记录一致时，可以继续展示。
- 卡牌中文名没有查到时，只要数字和内容正确，不应直接删除故事。
- 较长但读得通的故事应保留原文，不应强行截短。

### 数字错误

- 把最终数值说成增加量时，应删除或重写。
- 把未满生命说成满血时，应删除或重写。
- 引用对局中没有的伤害、生命或次数时，不应展示。
- 中文数字也要按相同规则检查。

### 文案不合适

- 带有明显程序用语的内容不应展示。
- 没有证据却说“本来一定能赢”等确定结论时，不应展示。
- 普通但内容真实的事件不能仅因为“不够特别”就在数字检查阶段被误删。

## 4. 趣味分与重写

- 每条通过数字和文案检查的故事按 0～3 分评价。
- 2 分及以上直接保留原文。
- 低于 2 分的故事只重写一次。
- 同一批故事中，高分故事保持不变，只重写低分故事。
- 重写后的故事需要再次检查数字、文案和趣味分。
- 重写后达到 2 分才展示。
- 重写后仍低分或数字错误时不展示，不能拿原来的低分故事补位。
- 没有可展示故事时，允许复盘不显示故事卡片。
- 没有有效分数或分数超出 0～3 时，该故事不展示。
- 完全相同的故事应先去重，再进行评分。

## 5. 界面检查

- 打开有数据、无数据和空复盘三种页面。
- 检查主数字条顺序和文案。
- 检查宽窗口和窄窗口下内容没有重叠或超出。
- 检查故事被删掉后，页面不会留下空白卡片或错误占位。

## 6. 通过标准

- 上述检查全部通过。
- 自动测试没有失败项。
- 错误数字和不合适文案不能出现在最终复盘。
- 低分故事最多重写一次，仍不合格时不展示。
