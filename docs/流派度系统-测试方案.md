# 流派度系统测试方案

## 测试哪些点

- 起始牌组不会被直接说成已经形成某个流派。
- 每条流派分别计算，不会互相覆盖。
- 加入关键牌、辅助牌、遗物和升级后，流派进度会正确变化。
- 缺少启动牌时只提示方向，不会误报已经成型。
- 重复牌达到需要数量后，不会一直增加分数。
- 无关牌会适当降低整体配合程度。
- 未知牌和动态效果会标为不确定，不会猜效果。
- 同一张牌在缺组件、配套完整和数量过多时，结果可以不同。
- 选牌前后显示的变化与实际重新计算结果一致。
- 多个流派同时成立时可以分别显示。
- 页面能显示流派分数、阶段和原因，特殊文字不会破坏页面。

## 通过标准

- 分数、阶段和提示与当前牌组一致。
- 不把未启动的流派说成已成型。
- 不因重复牌或无关牌产生明显虚高结果。
