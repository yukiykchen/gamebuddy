# 单局详情实现与验证

本次对应OpenSpec `add-local-run-details`。第一部分“本局复盘”已独立提交为`58d0f1b`；本次只实现其下方的“单局详情”。

## 实现结果

- 历史列表交互保留，展开后依次显示本局复盘与单局详情两个兄弟区域。
- 详情由独立事实投影和只读IPC提供，不导入复盘模块，不请求模型。支持结果、角色、进阶、到达楼层、记录时长、终局生命与金币。
- 分幕路线可点击跳至对应楼层，原生展开控件支持键盘；逐层显示已知战斗、选牌及未拿候选、事件选择、火堆、购买与资源观测变化。
- 终局遗物、牌组和药水使用中文名称及说明。相同牌合并数量，升级、附魔等变体分开。遗物获取楼层仅在明确获得或同层连续库存变化时展示，初次看到不等同在该层获得。
- 386张公开游戏图片保存到本地，约5.47 MB，来源及文件哈希见`src/assets/run-details/manifest.json`。运行时不依赖图片站。
- 详情独立缓存，复盘完成仅替换复盘区域；切换、清空、刷新后的迟到响应不会覆盖当前详情。

## 记录边界

旧日志的空回合字段不推算成玩家回合数，默认`victory=false`不当作战败，未通关不推断死因。购买价格已知但物品缺失时显示“物品未记录”。同层状态差分标为库存净变化，不将其绑定到某次购买或奖励；续局、采集中断和来源会话变化会中止差分。没有扩展游戏Mod协议，因此这些历史缺项无法追补。

本次验证了本地文件到Electron页面的完整读取与展示；未进行Windows实机开局、新Mod部署或新局端到端采集验证。

## 小卡面补充

终局牌组使用真实中文小卡面，普通和升级版分别匹配；显示尺寸为60×86 CSS像素，旁边保留名称与数量。没有新增悬停大图、点击放大或事件选择标注，原有文字说明保留。

新增1115张完整卡面和38张降级插画，资源限定为本地图鉴的577张卡牌对应版本。`WITHER`的中文升级图返回404，已记录到manifest的unavailable中并使用本地插画，升级名称和标记保留；未知扩展卡继续使用通用图标。全部1539张资源的文件哈希与清单一致，无未处理下载失败；资源总量约46.16 MB。

详情测试验证了普通／升级图片匹配、缺图降级及未知卡可读性。Electron在1400和850宽度检查最长真实局：17组卡牌均加载真实卡面，无破图或横向溢出；聚焦卡牌后尺寸不变，文字说明中没有大图。新增截图为`.runtime/review-profile/real-run-card-faces-wide.png`与`real-run-card-faces-narrow.png`。
