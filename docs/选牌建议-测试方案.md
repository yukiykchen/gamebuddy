# 选牌建议测试方案

## 测试哪些点

- 奖励页面出现时能读取全部候选牌，也能选择跳过。
- 推荐只会从当前候选牌和跳过中选择。
- 升级牌按升级后的效果判断。
- 根据当前牌组、遗物、药水、生命和后续敌人调整建议。
- 候选牌与当前流派有关时显示用途、缺口和冲突。
- 无关牌、未知牌和资料不足时不强行归入某个流派。
- 牌组已经较厚或候选价值低时可以建议跳过。
- 模型返回不存在的选项时，使用合法的本地结果。
- 模型失败或没有配置时，仍能看到本地建议。
- 离开奖励页面后旧建议会清理，晚到结果不会出现在新场景。
- 页面重连后可从奖励数据恢复，关闭奖励后立即清除。

## 通过标准

- 推荐不超出当前候选范围。
- 不编造卡牌效果、数量、流派或敌人。
- 模型不可用时功能仍可使用。
