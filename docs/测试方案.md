# GameBuddy 测试方案

## 1. 测试说明

本方案按用户实际使用链路测试，不只检查某个按钮或某段代码。每个功能都从“什么时候触发”开始，一直检查到数据处理、结果展示、场景结束和异常情况。

## 2. 复盘功能

```text
一局游戏结束
├─ 保存本局记录
│  ├─ 战斗、选牌、路线、休息处、事件和商店记录
│  ├─ 牌组、遗物、药水和最终状态
│  └─ 断线、续局和记录缺口标记
├─ 计算本局数字
│  ├─ 累计输出
│  ├─ 实际抗伤
│  ├─ 累计受伤
│  └─ 本回合最高出伤
├─ 生成复盘高光
│  ├─ 从真实记录中找候选内容
│  ├─ 检查数字和说法是否正确
│  ├─ 评价内容是否值得展示
│  ├─ 低分内容只重写一次
│  └─ 重写后仍不合格则不展示
├─ 展示复盘页面
│  ├─ 主数字条
│  ├─ 高光故事
│  ├─ 登塔路线
│  ├─ 最终牌组、遗物和药水
│  └─ 有结果、无结果和资料不足三种状态
└─ 异常处理
   ├─ 模型失败时保留本地数字
   ├─ 切换对局时旧结果不能串场
   ├─ 清空记录后旧结果不能恢复
   └─ 不完整对局不能冒充完整统计
```

重点测试：

- 最高回合出伤已知时显示正确数字，未知时显示“未记录”。
- 同一个最高出伤不能在页面中重复展示。
- 错误数字、没有证据的结论和明显不合适的说法不能发布。
- 高分内容保留原文，低分内容最多重写一次。
- 历史详情切换、关闭和清空后，页面保持正确。

## 3. 怪物弹幕

```text
进入战斗
├─ 识别当前场景
│  ├─ 战斗编号
│  ├─ 当前怪物
│  └─ 当前回合和怪物行动
├─ 生成怪物台词
│  ├─ 读取怪物名称和技能资料
│  ├─ 每次选择一只怪物
│  ├─ 相同怪物轮流说话
│  └─ 避免重复台词
├─ 排队和显示
│  ├─ 每回合限制数量
│  ├─ 技能说明优先保留
│  ├─ 本地台词与共享台词不互相阻塞
│  └─ 弹幕窗口显示详情
└─ 失效处理
   ├─ 怪物死亡后丢弃旧台词
   ├─ 怪物换行动后丢弃旧台词
   ├─ 离开战斗后清空队列
   └─ 新战斗重新建立场景
```

重点测试：

- 两只相同怪物不能在同一回合连续刷屏。
- 跨战斗不能频繁重复相同台词。
- 死亡怪物和过期行动的台词不能继续显示。
- 共享弹幕失败时，本地怪物弹幕仍能工作。

## 4. 生存弹幕

```text
收到新的战斗状态
├─ 读取真实变化
│  ├─ 玩家生命变化
│  ├─ 防御变化
│  ├─ 出牌记录
│  └─ 已确认的战斗高光
├─ 判断是否值得说话
│  ├─ 受伤
│  ├─ 生命充足
│  ├─ 低生命
│  ├─ 脱离危险
│  └─ 普通闲聊
├─ 生成角色台词
│  ├─ 使用当前角色口吻
│  ├─ 不猜伤害来源
│  ├─ 不把意图说成已经发生
│  └─ 不重复近期话题和笑点
├─ 控制播放节奏
│  ├─ 重要提醒优先
│  ├─ 普通台词保持间隔
│  └─ 没有新内容时可以不说
└─ 清理旧内容
   ├─ 断线
   ├─ 离开战斗
   ├─ 新开一局
   └─ 更换角色
```

重点测试：

- 生存台词只能来自真实生命和战斗记录。
- 重复状态不能制造新的受伤或高生命反应。
- 五个角色保持各自口吻。
- 模型失败、格式错误或内容重复时不能显示错误台词。

## 5. 流派度系统

```text
读取当前牌组
├─ 整理牌组信息
│  ├─ 卡牌和数量
│  ├─ 升级状态
│  ├─ 遗物
│  └─ 未知或动态效果
├─ 分别计算每条流派
│  ├─ 启动组件
│  ├─ 资源供给
│  ├─ 循环方式
│  ├─ 防御和输出
│  └─ 缺口和冲突
├─ 计算选牌前后变化
│  ├─ 加入候选牌前
│  ├─ 加入候选牌后
│  ├─ 分数变化
│  └─ 阶段变化
├─ 展示结果
│  ├─ 当前分数
│  ├─ 当前阶段
│  ├─ 主要原因
│  └─ 最多展示重要变化
└─ 防止误判
   ├─ 起始牌组不算成型
   ├─ 重复牌达到需要后不无限加分
   ├─ 无关牌造成稀释
   └─ 未知牌不猜效果
```

重点测试：

- 不同流派独立计算，可以同时成立。
- 缺启动组件时只能提示方向。
- 选牌前后变化必须等于重新计算的差值。
- 重复牌、无关牌和未知牌的处理正确。

## 6. 个人总结

```text
打开个人总结
├─ 读取个人资料
│  ├─ 个人编号
│  ├─ 显示名称
│  └─ 默认名称
├─ 读取历史记录
│  ├─ 已完成对局
│  ├─ 本地复盘
│  ├─ 单局详情
│  └─ 排行和上传状态
├─ 页面操作
│  ├─ 修改名称
│  ├─ 展开一局
│  ├─ 切换对局
│  ├─ 关闭详情
│  └─ 清空历史
└─ 防止旧数据串场
   ├─ 切换时忽略上一局晚到结果
   ├─ 清空后忽略旧请求
   └─ 页面重开时读取当前资料
```

重点测试：

- 个人编号首次生成后保持不变。
- 名称能保存，空名称恢复默认值。
- 有记录、无记录和资料不足状态都能正常显示。
- 清空和切换后不能出现旧内容。

## 7. 选牌建议

```text
打开卡牌奖励
├─ 读取当前局面
│  ├─ 候选牌和升级状态
│  ├─ 当前完整牌组
│  ├─ 遗物和药水
│  ├─ 生命、金币和章节
│  └─ 地图及后续敌人
├─ 分析每张候选牌
│  ├─ 卡牌实际效果
│  ├─ 当前牌组缺口
│  ├─ 流派配合
│  ├─ 风险和冲突
│  └─ 是否应该跳过
├─ 生成合法选择
│  ├─ 本地规则先给结果
│  ├─ 可选模型进行复核
│  ├─ 模型只能选择现有候选
│  └─ 非法结果退回本地选择
├─ 展示建议
│  ├─ 推荐牌或跳过
│  ├─ 主要理由
│  ├─ 流派提示
│  └─ 风险说明
└─ 场景结束
   ├─ 奖励关闭后清理建议
   ├─ 重连时可从奖励状态恢复
   └─ 晚到结果不能进入新场景
```

重点测试：

- 推荐不能超出当前候选牌和跳过。
- 升级牌按升级后的实际效果判断。
- 未知牌和无关牌不能被强行归入流派。
- 没有模型或模型失败时仍能使用。

## 8. 路线建议

```text
打开地图
├─ 读取地图
│  ├─ 当前节点
│  ├─ 可点击入口
│  ├─ 后续节点
│  └─ 路线是否完整
├─ 判断是否需要建议
│  ├─ 单一路线不提示
│  └─ 多个入口开始比较
├─ 比较路线
│  ├─ 当前生命
│  ├─ 精英风险和收益
│  ├─ 火堆、商店和宝箱
│  ├─ 连续战斗压力
│  └─ 后续路线灵活性
├─ 生成合法结果
│  ├─ 只能选择当前入口
│  ├─ 低生命启用安全限制
│  ├─ 模型非法选择退回本地结果
│  └─ 分数接近时给暂时首选
└─ 展示与清理
   ├─ 显示左、右或从左第几个
   ├─ 路线不完整时提示
   └─ 离开地图或进入战斗后清理
```

重点测试：

- 不能推荐无法点击的节点。
- 高、中、低生命的取舍不同。
- 同类型入口也能明确区分。
- 路线接近时不能只写“任选”。

## 9. 休息处、事件和商店建议

```text
进入非战斗选择场景
├─ 休息处
│  ├─ 读取当前生命
│  ├─ 列出真实可升级卡牌
│  ├─ 比较回血和升级
│  └─ 结合后续强敌给出结果
├─ 事件
│  ├─ 读取当前页面真实选项
│  ├─ 检查金币和资源条件
│  ├─ 排除锁定或可能致命选项
│  └─ 资料不足时不强行推荐
├─ 商店
│  ├─ 读取当前库存和价格
│  ├─ 计算金币预算
│  ├─ 组合购买、删牌或保留金币
│  └─ 一次给出完整购物清单
├─ 模型复核
│  ├─ 只能选择规则生成的合法方案
│  └─ 失败时使用本地结果
└─ 离开场景
   ├─ 清理旧建议
   └─ 不让晚到结果重新出现
```

重点测试：

- 休息处不能推荐不存在的升级。
- 事件不能推荐金币不足、锁定或致命选项。
- 商店不能超预算或推荐已售出商品。
- 资料不足时不能默认选择第一个选项。

```text
启动 GameBuddy
├─ 创建窗口
│  ├─ 主面板
│  ├─ 桌宠
│  ├─ 弹幕窗口
│  ├─ 个人总结
│  └─ 模型设置
├─ 接收并展示内容
│  ├─ 游戏状态
│  ├─ 各类建议
│  ├─ 流派信息
│  ├─ 弹幕
│  └─ 复盘和个人总结
├─ 用户操作
│  ├─ 展开和收起建议
│  ├─ 显示和隐藏窗口
│  ├─ 悬停和点击弹幕
│  └─ 修改模型设置
└─ 窗口异常处理
   ├─ 加载中关闭
   ├─ 重复打开和关闭
```

重点测试：

- 弹幕窗口不能抢走游戏焦点。
- 旧窗口消息不能写入新窗口。
- 正常、空数据和资料不足页面都能显示。

## 11. 状态连接与回放

```text
游戏或 Replay Bridge
├─ 发送数据
│  ├─ 状态快照
│  ├─ 战斗事件
│  ├─ 选牌、地图、休息处和事件
│  └─ 商店和对局结束记录
├─ 接收和检查
│  ├─ 检查数据格式
│  ├─ 过滤重复消息
│  ├─ 保存最新状态
│  └─ 标记数据是否过期
├─ 分发到各功能
│  ├─ 建议系统
│  ├─ 弹幕系统
│  ├─ 流派系统
│  ├─ 复盘记录
│  └─ 主界面和桌宠
├─ 回放
│  ├─ 读取固定状态
│  ├─ 读取固定事件
│  ├─ 重现生命周期
│  └─ 检查结果可重复
└─ 异常处理
   ├─ Bridge 断开
   ├─ 数据停滞
   ├─ 重复状态
   └─ Mod 文件缺失
```

重点测试：

- 状态和事件格式正确。
- 战斗开始、回合开始、战斗结束和地图事件顺序正确。
- 重复消息不会重复触发功能。
- Replay Bridge 可以连接并发送第一份状态。

## 12. 通过标准

- 每条链路从输入到展示都能走通。
- 所有自动测试没有失败项。
- 页面检查没有报错、错位或旧内容串场。
- 建议只能使用当前真实选项。
- 弹幕和复盘不能编造没有记录的事实。
- Windows 真机、真实游戏和真实在线模型未验证时，报告必须明确标注。
