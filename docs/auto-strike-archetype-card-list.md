# 铁甲「自动打击流」牌表 · 最终方案

判定主轴（卡面，不是臆测）：

1. **地狱狂徒**：抽到名字里带「打击」的牌时，自动对随机敌人打出。
2. **完美打击**：牌组里名字带「打击」的牌越多，伤害越高。

```text
流派度 = 自动打击「完整度 / 稳定度」
≠ 整副牌强度 ≠ 保命能力
能赢 ≠ 属于这个流派
```

本文档是三路对比后的**锁定归属**（核心 / 辅助 / 防御贡献）。计分已落地于 `agent/knowledge/auto-strike.js`（change: `refine-auto-strike-scoring`）。

---

## 流派度会考虑什么（总览）

一句话：**这副牌离「地狱狂徒稳定自动打打击 + 完美打击结算」有多近。**

| 计入 | 问的是什么 | 典型信号 |
| --- | --- | --- |
| **启动** | 有没有地狱狂徒 | 有 → 流派成立；没有 → 其余大幅打折 |
| **循环** | 能不能持续抽到打击 | 剑柄、劫掠；饱和后边际变小 |
| **输出** | 有没有终结技 | 完美打击 |
| **弹药** | 打击包够不够喂狂徒/完美 | 打击 / 双重 / 预备（低正、强递减） |
| **引擎辅助** | 过牌 / 回顶 / 换能是否服务循环 | S：祭品、燃烧契约；A：耸肩、头槌、战鼓、杂耍、放血 |
| **开局摸到核的概率** | 牌组厚度 vs 关键件密度 | 太厚会压 setup（软稀释） |
| **相关遗物** | 是否直接帮打击轴 | 打击木偶、准备背包等 |
| **混合防（例外）** | 防牌是否顺便推进循环 | 耸肩（过牌）、狂怒（有狂徒时连打协同） |
| **软反** | 是否把身份拖去别的轴 | 力量支线、非打击肥攻、壁垒身份 → 中负 |
| **硬毒** | 是否直接毁关键字/引擎 | 原始力量、恶魔之焰、恶魔形态、腐化、切断 → 大负 |

**明确不考虑 / 不当加成：**

- 纯保命、纯墙（防御、壁垒、坚定不移…）→ 最多稀释，不抬分  
- 一般「好牌但无打击名」→ 不因能赢而加分  
- 战斗专注 → 不当成熟件（锁抽，最多 B）  
- 胜率、血量、遗物综合强度、事件好运

**100% 成熟只看：** 狂徒 + 循环饱和 + 完美 + 至少一张 S 过牌（祭品或燃烧契约）。B 档、混合防、遗物都不进门槛。

**UI 原因标签：** `过牌辅助` / `连打协同` / `稀释` / `支线冲突` / `破坏循环`。

## 0. 三路结论摘要

| 议题 | 结论 |
| --- | --- |
| 核心 | 必备四核：地狱狂徒、剑柄打击、劫掠、完美打击 |
| 打击包 | 基础打击 / 双重 / 预备 = 弹药（有狂徒后低正、强递减）；灰烬弱可选 |
| 辅助 | 祭品 / 燃烧契约 = S；耸肩 / 头槌 / 战鼓 / 杂耍 = A；放血 = A−；战斗专注 = B（锁抽）；添柴 / 重振 = B；坚定不移 / 痛击额外 = 移出 |
| 防御 | **模型 B**：纯墙永不抬流派度，只稀释；只有服务循环的混合防给小正 |
| 坏牌减分 | 现码几乎只有厚度 0～−2；补三档：稀释 / 软反 / 硬毒（原始力量等 −12～−18） |

## 1. 最终归属表

### 1.1 必备四核

| ID | 名称 | 槽位 | 模拟（现码 early） | 读法 |
| --- | --- | --- | --- | --- |
| `HELLRAISER` | 地狱狂徒 | 启动 | — | 没有它不算这个流派 |
| `POMMEL_STRIKE` | 剑柄打击 | 循环 | +34 | 早期最值钱的一张 |
| `PILLAGE` | 劫掠 | 循环 | +24 | 无「打击」名仍是循环定义件 |
| `PERFECTED_STRIKE` | 完美打击 | 输出 | +5 | 终点；早期弱于循环，成型后仍正 |

### 1.2 打击包（弹药，非必备门槛）

有地狱狂徒后给**低正弹药分**，强递减；无狂徒时 ≈ 0。  
**现码给 0 / −1 是盲区，不是卡面无效。**

| ID | 名称 | 档 | 目标 Δ（设计） |
| --- | --- | --- | --- |
| `STRIKE_IRONCLAD` | 打击 | 基础弹药 | early +1～+2 → 厚组 0 / 小负 |
| `TWIN_STRIKE` | 双重打击 | 优质弹药 | 略高于基础打击 |
| `SETUP_STRIKE` | 预备打击 | 优质弹药 | 同双重 |
| `ASHEN_STRIKE` | 灰烬打击 | 弱可选 | 再低一档；不当成熟门槛 |

排除：他角打击、无色衍生打击、力量轴、无「打击」名纯输出。

### 1.3 辅助分档（S / A / B / out）

| 档 | ID | 名称 | 判定 | 相对现码 |
| --- | --- | --- | --- | --- |
| **S** | `OFFERING` | 祭品 | 抽 3 + 能，**不锁抽** | 保留最高权 |
| **S** | `BURNING_PACT` | 燃烧契约 | 清废 + 抽 2 | 保留高权 |
| **A** | `SHRUG_IT_OFF` | 耸肩无视 | 格挡 + 抽 1（混合防，见 §2） | **新进**；现码 mid −1 错误 |
| **A** | `HEADBUTT` | 头槌 | 回顶关键件 | **新进** |
| **A** | `DRUM_OF_BATTLE` | 战鼓 | 抽 2；消耗回能 | **新进** |
| **A** | `JUGGLING` | 杂耍 | 攻击连打复制 | 保留，可略低于真抽牌 |
| **A−** | `BLOODLETTING` | 放血 | 0 费换能，解 2 费瓶颈 | **新进** |
| **B** | `BATTLE_TRANCE` | 战斗专注 | 抽 3 但**锁死本回合后续抽** | 从「强纳入」**降到 B** |
| **B** | `STOKE` | 添柴 | 重整手牌；多半「入手」不触发狂徒 | **降权**（现 0.25 过高） |
| **B** | `SECOND_WIND` | 重振精神 | 清非攻击换格挡 | 弱保留 / 可只给微量 |
| **B** | `RAGE` | 狂怒 | 攻击触发格挡（混合防） | 条件小正（有狂徒） |
| **B** | `DARK_EMBRACE` | 黑暗之拥 | 仅已有消耗包时 | 条件 |
| **out** | `UNMOVABLE` | 坚定不移 | 纯墙倍增，零循环 | **移出**（现码 0.1 误计） |
| **out** | `BASH` 额外 | 痛击 | 易伤工具 | **移出流派辅助** |
| **out** | `TRUE_GRIT` / `FEEL_NO_PAIN` / `ARMAMENTS` | 坚毅 / 无惧疼痛 / 武装 | 质量或另一支线 | 不进成熟清单 |

#### 战斗专注为什么不是 S

```text
祭品:     抽3 → 狂徒触发 → 剑柄再抽 → 继续  ✓
战斗专注: 抽3 → 狂徒触发 → 剑柄再抽 ✗锁死 → 本回合引擎停
```

可当「找启动时的一次性挖牌」，不当成熟必备，也不该和祭品同权。

## 2. 防御牌怎么贡献流派度（模型 B）

**明确口径：防御牌不是流派核心，默认不抬流派度；只有服务「抽打击 → 自动打出」循环的混合防才给小正分。**

| 类型 | 代表 | 规则 | UI 原因标签 |
| --- | --- | --- | --- |
| 纯墙 | 防御、壁垒、岿然不动、血墙、坚定不移 | **永不给正**；只吃厚度稀释（通常 0～−2） | `稀释` |
| 格挡+过牌 | 耸肩无视 | **小正**（弱于祭品/燃烧契约）；净贡献应 ≥ 0 | `过牌辅助` |
| 攻击触发格挡 | 狂怒 | **条件小正**：已有地狱狂徒 +1～+2；无启动核按纯墙 | `连打协同` |
| 消耗/清手防 | 重振精神、无惧疼痛 | 条件弱正或 0；不当核心 | `清手辅助` |

约束：混合防进 support 桶，单张天花板远低于剑柄/劫掠/祭品；同名第二张边际递减；**壁垒永不进 support**。

### 设计目标 Δ（非现码）

| 候选 | 早期（有狂徒+剑柄） | 成型偏厚 | 读法 |
| --- | --- | --- | --- |
| 防御 | −1% | −1%～−2% | 纯稀释 |
| 耸肩无视 | +3% | +1%～+2% | 过牌辅助 > 厚度惩罚 |
| 狂怒（有狂徒） | +2% | +1% | 连打协同 |
| 壁垒 | −1% | −1%～−2% | 与防御同档 |

现码对照：耸肩 / 狂怒 / 双重打击 mid 阶段都被打成 **−1**（只认厚度），正是要修的。

## 3. 模拟：有了这些牌对流派是好是坏

场景用**现码**（只认四核 + 旧 SUPPORT_RATES），用来暴露盲区；括号内是最终方案应有的方向。

| 阶段 | 牌组概况 | 分数 | 关键观察 |
| --- | --- | --- | --- |
| Early | 起手 + 地狱狂徒 | 13.5 | 剑柄 +34、劫掠 +24 → 循环是第一优先级 |
| Mid | +2 剑柄 | 60.3 | 循环仍正；**耸肩/头槌/双重 −1**（现码错判稀释） |
| Near | +劫掠+完美+祭品+燃烧契约+双重+预备 | 70.1 | 四核仍小正；未计打击包弹药；坚定不移仍能吃到旧辅助分 |

**对流派好坏（最终方案语义，不是「能不能赢」）：**

| 拿牌 | 对自动打击流 | 说明 |
| --- | --- | --- |
| 剑柄 / 劫掠 | 大好 | 循环定义 |
| 完美打击 | 好 | 输出终点 |
| 双重 / 预备 / 基础打击（有狂徒） | 小好→边际变 0 | 弹药；堆太多才稀释 |
| 祭品 / 燃烧契约 | 大好 | S 辅助 |
| 耸肩 / 头槌 / 战鼓 | 好 | A；现码漏算 |
| 放血 | 小好 | 解费，不抽牌 |
| 战斗专注 | 情境好 / 成型同回合坏 | B，不进 100% 必备 |
| 添柴 | 成型小好 | B，降权 |
| 狂怒（有狂徒） | 小好 | 连打协同，不是墙 |
| 防御 / 壁垒 / 坚定不移 | 中性偏坏 | 只稀释，不抬流派 |
| 力量轴 / 无打击名输出 | 不抬流派 | 另一条轴或纯输出 |

粗结论：**四核 + S/A 过牌 + 适量打击包 = 流派变好；纯墙和力量轴不帮流派度；战斗专注不要当成熟件。**

## 4. 100% 成熟（锁定）

同时满足才算「成熟自动打击」：

1. 地狱狂徒 ≥ 1  
2. 循环饱和：剑柄打击与劫掠合计达到「再拿边际明显变小」（实现时用饱和曲线，不必写死张数）  
3. 完美打击 ≥ 1  
4. 至少 1 张 **S** 级过牌：祭品 **或** 燃烧契约（**不含**战斗专注）  
5. 打击包有最低厚度（起手打击即可；双重/预备算进厚度但不强制）

B 档与混合防**不进** 100% 门槛；最多给未封顶时的少量加分。

## 5. 坏牌怎么减分（此前缺口 · 现补上）

### 5.1 现状：几乎没认真减

现码负分只有两条：

| 机制 | 幅度 | 问题 |
| --- | --- | --- |
| 牌组变厚 → `setupProbability` 下降 | 通常 **0～−2** | 防御 / 力量轴 / 恶魔之焰看起来差不多 |
| 第二张起多余地狱狂徒 | `−3 × (张数−1)` | 与「反协同牌」无关 |

**没有硬毒表。** 力量轴、手牌清空、腐化等在 UI 上常显示 0，和「真在破坏循环」分不开——这是不诚实的。

### 5.2 三档负分（最终方案）

```text
软稀释          软反协同              硬毒
0 ~ -2          -5 ~ -9               -12 ~ -18
厚了/占坑       抢身份/吃弹药边际      直接毁循环或换轴
标签: 稀释      标签: 支线冲突         标签: 破坏循环
```

口径仍是 **流派完整度 ≠ 胜率**：硬毒 =「离自动打击流更远」，不是「绝对不能赢」。

### 5.3 硬毒（一选就大掉流派分）

这些才接近你说的「绝对不能为了这个流派去选」：

| ID | 名称 | 为何是毒 | 建议 Δ（有狂徒后） |
| --- | --- | --- | --- |
| `PRIMAL_FORCE` | 原始力量 | 手牌攻击变巨石 → 打击包/剑柄关键字没了 | **−18** |
| `FIEND_FIRE` | 恶魔之焰 | 清空手牌消耗 → 吃掉剑柄与打击弹药 | **−15** |
| `DEMON_FORM` | 恶魔形态 | Rare 锁进力量轴，占奖励与构筑身份 | **−14** |
| `CORRUPTION` | 腐化 | 技能全耗 → 祭品/燃烧契约/耸肩引擎自毁 | **−13** |
| `SEVERANCE` | 切断 | 抽/手/弃塞灵魂 → 堵抽、停劫掠 | **−12** |

接近硬毒下沿（−10～−12）：`BRAND` 烙印、`HAVOC` 破灭（随机打出并消耗，可能吞剑柄/狂徒）。

单张硬毒 **不要超过 −20**（对照早期剑柄约 +34，UI 仍可读）；同名第二张边际递减。

### 5.4 软反（中罚，不是「随便拿」）

| 簇 | 例子 | 建议 Δ |
| --- | --- | --- |
| 力量支线 | 燃烧、撕裂、疯狂进食 | −6～−8 |
| 非打击肥攻 | 旋风斩、暴走、愤怒、狂宴 | −5～−7（劫掠仍能挖攻击，但不触发狂徒） |
| 锁抽 | 战斗专注（成型同回合） | 约 −6；仅找启动时可放宽 |
| 纯墙身份 | 壁垒、巩固、血墙 | 壁垒等 −5；普通防御维持稀释 |
| 消耗终点 | 契约终结；无惧疼痛（无消耗包时） | −5 |
| 随机塞攻 | 地狱之刃 | −5 |

铁斩波、全身撞击：**最多软反/稀释，不当硬毒。**

### 5.5 「绝对禁拿」要不要单独徽章？

**不要。** 只做大负分 + 原因标签（`破坏循环` / `支线冲突` / `稀释`）。

理由：生存局仍可能拿壁垒；单独「永不拿」会和选牌教练打架，并假装流派度 = 胜率。诚实信号就是 **−15 破坏循环**，不是第二套禁令。
