# 个人总结测试方案

## 测试哪些点

- 第一次使用时会生成固定的个人编号和默认名称。
- 再次打开时个人编号保持不变。
- 修改名称后可以保存，首尾空格会被去掉。
- 名称为空时恢复默认名称。
- 总结页面能显示已有记录、没有记录和资料不足三种状态。
- 历史列表可以展开、切换和关闭。
- 清空历史后页面同步清空。
- 切换对局或清空记录时，晚到的旧结果不能覆盖当前页面。
- 窄窗口和宽窗口下内容都能正常显示。
- 本地记录不会因为页面刷新而错误串到其他玩家。

## 通过标准

- 名称和个人编号保存正确。
- 历史总结能正常打开、切换和清空。
- 页面没有旧数据串场、错位或横向溢出。
