# GameBuddy 测试报告

测试日期：2026-11-11  
测试分支：`codex/recap-peak-turn-damage`  
测试对象：当前分支工作区  
测试环境：macOS、Node.js 26.8.1、npm 11.19.0

## 1. 总体结果

本次自动测试全部通过，没有失败项。

- 复盘相关测试：91 项通过。
- 怪物、生存和其他弹幕测试：96 项通过。
- 流派系统测试：56 项通过。
- 选牌和构筑指导测试：32 项通过。
- 路线、休息处、事件和商店建议检查：82 项通过。
- 基础 Agent 测试：5 项通过。
- 状态、回放和 Mod 文件检查：29 项通过。
- 模型设置测试：9 项通过。
- 桌宠窗口基础测试：3 项通过，并通过 8 次加载中关闭检查。
- 各功能页面检查全部通过。
- 全部脚本语法检查通过。

## 2. 复盘功能结果

- 累计输出、实际抗伤、累计受伤和本回合最高出伤显示检查通过。
- 最高回合出伤为 50 时正确显示 50。
- 缺少完整记录时显示“未记录”，不会显示为 0。
- 同一个最高出伤不会在其他纪录中重复显示。
- 错误数字、把最终值说成增加量、把未满生命说成满血等内容会被拦截。
- 没有证据的确定胜负结论和明显程序用语会被拦截。
- 高分故事保留，低分故事只重写一次。
- 重写后仍低分或数字错误的故事不会显示。
- 没有合格故事时可以显示空结果。
- 历史对局、单局详情、路线、牌组和遗物显示检查通过。
- 切换对局、清空记录和旧结果晚到的处理通过。

## 3. 怪物弹幕结果

- 怪物开场台词和技能详情显示通过。
- 两只相同怪物会轮流说话，同一回合不会连续刷多条。
- 跨战斗台词去重通过。
- 怪物死亡、行动变化和切换战斗后，旧台词会被丢弃。
- 共享弹幕失败时，本地怪物信息仍能显示。
- 弹幕窗口没有抢焦点，悬停和点击正常。

## 4. 生存弹幕结果

- 受伤、生命充足和战斗记忆只使用真实记录。
- 重复状态、断线和切换场景不会制造假的生命变化。
- 旧的高生命台词会在生命下降后失效。
- 生命和防御话题会限制重复。
- 五个角色的说话风格检查通过。
- 模型失败、无效内容和重复内容的处理通过。

## 5. 流派度系统结果

- 56 项自动测试全部通过。
- 起始牌组、未启动、已启动、并列和多流派情况检查通过。
- 关键牌、辅助牌、遗物、升级和牌组厚度会正确影响结果。
- 重复牌饱和、无关牌稀释和未知牌不猜测的检查通过。
- 选牌前后变化与重新计算结果一致。
- 铁甲战士四套流派的卡牌资料完整。
- 流派页面显示检查通过。

## 6. 个人总结结果

- 个人名称和个人编号保存测试通过。
- 重复读取时个人编号保持不变。
- 名称首尾空格会被去掉，空名称会恢复默认名称。
- 历史记录、展开详情、切换对局和清空记录检查通过。
- 旧结果晚到时不会覆盖当前页面。
- 有结果、无结果和资料不足三种页面状态通过。
- 宽窗口和窄窗口显示通过。

## 7. 选牌建议结果

- 32 项选牌和构筑指导测试全部通过。
- 当前候选、跳过、升级牌和未知牌处理通过。
- 牌组、流派、遗物和商店相关提示通过。
- 虚构数量、假成型、错误混合建议和非法选项会被拒绝。
- 模型失败或没有模型时，本地建议仍可显示。
- 场景切换后的晚到结果会作废。
- 奖励页面重连恢复和关闭清理通过。
- 五角色选牌页面显示通过。

## 8. 路线建议结果

- 推荐只使用当前真实入口。
- 高、中、低生命三种取舍通过。
- 低生命时会拒绝明显更危险的模型选择。
- 商店、精英、火堆、宝箱和后续节点比较通过。
- 左右入口、四个入口和相同类型入口标签通过。
- 分数接近时会给暂时首选，不会只写“任选”。
- 单一路线不会触发建议。
- 模型失败后的本地结果和旧场景清理通过。

## 9. 休息处、事件和商店结果
