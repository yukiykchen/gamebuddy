# 路线建议测试方案

## 测试哪些点

- 只有出现多个可走入口时才给路线建议。
- 推荐的入口必须是地图上当前可以点击的入口。
- 高生命、中等生命和低生命使用不同的取舍。
- 生命较低时不会为了精英奖励忽略明显风险。
- 生命健康时可以考虑精英、商店、火堆和宝箱收益。
- 同类型入口能用左侧、右侧或从左第几个区分。
- 分数接近时仍给一个暂时首选，并说明差距不大。
- 地图路线不完整时明确提示，不假装已经看完全部路线。
- 模型只能在现有路线中选择，非法结果会回到安全结果。
- 单一路线时不重复打扰玩家。
- 切换地图或进入战斗后，旧路线建议会清理。

## 通过标准

- 不推荐无法点击或不存在的路线。
- 低生命时安全限制生效。
- 路线标签清楚，旧建议不会串到新场景。
