# 怪物弹幕测试方案

## 测试哪些点

- 进入战斗时，怪物会说一条与自己和技能有关的话。
- 两只相同怪物轮流说话，同一回合不会连续刷多条。
- 同一句怪物台词不会在不同战斗中反复出现。
- 怪物已经死亡、换了行动或离开战斗后，排队中的旧台词不会再显示。
- 敌人死亡、召唤和短暂无敌人数据时，不会重复触发开场台词。
- 新战斗能正确开始新一轮弹幕。
- 怪物技能说明不会被普通闲聊挤掉。
- 共享弹幕读取失败时，本地怪物弹幕仍能使用。
- 弹幕窗口不会抢走游戏焦点，鼠标经过时仍能正常操作。

## 通过标准

- 台词来自当前怪物和当前场景。
- 不重复刷屏，不显示已经过期的怪物台词。
- 弹幕出现和关闭不会影响游戏窗口操作。
