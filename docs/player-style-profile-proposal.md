# 玩家风格画像改版建议

## 已落实的统计口径

- 五星图和近期统计使用全角色最近50局，先按结束时间选窗口，再聚合行为；主角色只表示使用偏好，不过滤图表。
- 主角色由该窗口使用次数最多者决定，并列时最近使用者优先；主角色局数与全体样本数分别显示。
- 近期统计精简为通关率、平均进度、精英挑战、最多连胜。最多连胜按同一最近50局窗口计算，失败/主动放弃中断，以次数展示。
- 通关、未通关、主动放弃分开。放弃的实际行为仍是样本，胜率只用胜利和失败；仅退出游戏或断线不能证明放弃。
- 三局门槛按全角色合计。若局数足够但某维度没记录到行为，提示缺哪项数据，不再说“再完成0局”。

## 为什么现有五星图缺乏吸引力

此前版本是五个行为计数经过缩放后画在一起。进攻出牌主要反映职业与牌组结构；火堆升级没有结合生命与眼前危险；精英占比到30%就填满；消费混合了进店频率和花钱比例。玩家容易把外圈理解成满分，但这些数值既不能代表水平，也很难回答“我是怎样的玩家”。

建议保留五向图作为视觉锚点，把产品主体改成“风格称号＋五种取舍＋三个真实证据＋近期变化”。不追求五项全部拉满，不用AI补出看似完整的人格。

## 建议的五个方向

| 方向 | 两端含义 | 可观测依据 | 如何减少误判 |
| --- | --- | --- | --- |
| 战斗节奏 | 稳步展开 ↔ 快速压制 | 前几回合输出占比、输出集中在哪些回合、准备能力与兑现先后、战斗回合数 | 区分敌人、章节、职业及战斗长度；攻击牌比例不直接等于激进 |
| 构筑取向 | 厚牌工具箱 ↔ 精简循环 | 奖励拿取/跳过、删牌、净牌组变化、重复过牌与回收的实际使用 | 不把小牌组当更好，不重新引入流派度或凭几张牌宣布循环成型 |
| 挑战偏好 | 稳健推进 ↔ 主动迎战 | 有精英可选时是否选择、选择时生命与药水、当时的替代路径 | 只计算真实可选机会；被迫打精英不能说成喜欢冒险 |
| 资源取舍 | 即时安全 ↔ 长期投资 | 火堆回血/升级及当时生命、买药与永久组件、临近威胁下的支出 | 缺血时回血不是保守缺点，花完钱不是投资能力高 |
| 探索偏好 | 确定收益 ↔ 未知尝试 | 有问号/明确房间可选时的路线、事件实际选项和明确风险 | 不把被迫路径、未知效果或版本缺数据当成主动冒险 |

这些是待确认的新方向，本轮没有把它们替换进运行时评分。

## 画像怎样让玩家想看

1. **一句能认出自己的称号。**例如“偏爱精简的冒险家”或“先站稳再收尾”。标签不是固定人格诊断，近期风格改变时可以变化。
2. **三个具体证据。**例如“有其他路线时，你仍更常选择精英”“拿牌时更常跳过奖励”。上线时必须给出真实次数、机会分母和窗口；这里是文案例子，不是当前玩家结论。
3. **和自己的过去比较。**展示最近10局相较此前窗口的变化，例如构筑更精简、挑战选择更频繁。职业比例、章节和样本机会差异太大时，不硬说成长或退步。
4. **一张可分享的风格卡。**角色偏好、称号、五向形状、一个最鲜明的真实习惯即可。胜率和最高伤害作为旁边的战绩，避免与风格混成能力评分。

建议图中少强调0–100分，多强调当前倾向、另一端的含义和证据局数。页面可显示有数据的维度与“还在认识你”的空缺，而不是用默认50分补齐。

## 计算与AI分工

- 规则计算机会、选择、比例、分组和可信程度，保留分子分母。先在相近职业/章节/遭遇条件下比较，再汇总跨职业风格，不能拿所有职业的原始攻击比例直接混算个性。
- 少量样本展示事实，不急着给强称号。画像需要的门槛应按有效选择机会决定，三局只能说明界面可以开始有内容，不意味着人格已经稳定。
- AI可在合法标签和已核实证据中挑选称号、润色一句描述。不能修改指标、发明证据、把没有观察到的行为写成“不喜欢”，也不需要上传完整本地历史。是否接入模型需要后续单独确定数据边界。

## 当前数据与下一步

已有本地数据：角色、章节、牌组变化、打牌、回合、伤害、奖励、商店交易、火堆选择和部分决策上下文。可以先改好全角色统计，再用真实日志验证节奏和构筑取向。

需要核实/补齐：路线选择当时有哪些替代路径、选择时生命和药水、事件风险是否明确，以及伤害目标与有效战斗回合是否完整。没有这些信息时，“挑战”和“探索”先展示记录事实，不给强风格结论。

上线前应选取至少五种反例：小刀高频攻击但主要靠防御、厚牌组工具箱、精简循环、低血量被迫回血、精英只有唯一可达路径。风格结论必须能区分这些情况，再考虑添加分享和长期称号。

本文件是面向后续版本的建议，不覆盖工作区当前已有五星图公式；本轮统计条调整只作用于四项近期统计。
