# 休息处、事件和商店建议测试方案

## 休息处

- 低生命时比较回血和升级，不盲目升级稀有牌。
- 生命健康时能识别有明显提升的升级。
- 只能推荐真实可升级的牌。
- 休息处关闭后建议会清理。

## 事件

- 只从当前页面实际显示的选项中选择。
- 金币不足、锁定或可能致命的选项不能被推荐。
- 资料不足时不默认选择第一个选项。
- 动态数值和当前资源会进入判断。

## 商店

- 使用当前库存、价格和金币。
- 总花费不能超过金币。
- 可以购买多件，也可以建议保留金币。
- 已售出、价格未知或库存外的物品不能被推荐。
- 同一次进店给出完整清单，不在每次购买后反复改口。

## 通过标准

- 所有建议都来自当前真实选项。
- 不超预算，不推荐不可用或危险选项。
- 离开场景后旧建议不会继续显示。
