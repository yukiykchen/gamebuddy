# 状态连接与回放测试方案

## 测试哪些点

- 状态数据和事件数据格式正确。
- 能读取角色、生命、牌组、地图、战斗和奖励等基础内容。
- 重复消息不会造成重复处理。
- 战斗开始、回合开始、战斗结束和打开地图事件顺序正确。
- 最新状态、事件记录和数据新鲜程度能正确更新。
- 固定回放可以读取并重复运行。
- 录制的状态和事件可以重新回放。
- Replay Bridge 能建立连接并发送第一份状态。
- Bridge 断开后不会把旧数据当成新数据。
- Mod 目录中的必要文件和代码结构完整。

## 通过标准

- 协议、事件、观察数据和回放检查全部通过。
- Replay Bridge 可以连接并收到状态和生命周期事件。
- 旧消息和重复消息不会产生重复结果。
