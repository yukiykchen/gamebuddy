# 桌宠与主界面测试方案

## 测试哪些点

- 桌宠能正常创建、关闭、重新打开和重复关闭。
- 窗口正在加载时关闭，不会出现错误。
- 旧窗口的晚到消息不会写到新窗口。
- 弹幕窗口保持透明，不抢焦点。
- 鼠标经过可交互区域时能点击，离开后恢复穿透。
- 选牌、商店、流派、弹幕和复盘内容能正确显示。
- 建议详情能展开和收起。
- 空数据、资料不足和正常数据都有可读页面。
- 模型设置窗口能打开、隐藏、重新打开和保存。
- 模型服务失败时能回到原有设置或本地结果。

## 通过标准

- 所有窗口能稳定打开和关闭。
- 页面没有破图、明显错位或旧内容串场。
- 桌宠和弹幕不会抢走游戏操作焦点。
