# 生存弹幕测试方案

## 测试哪些点

- 玩家受伤、生命充足、低生命和脱险时，只根据真实记录说话。
- 不把敌人意图说成已经造成伤害。
- 不把某张攻击牌说成一定打中了敌人。
- 相同生命或防御话题不会连续重复。
- 旧的高生命台词在生命下降后不会继续显示。
- 同一场战斗的重要生存提醒不会重复播报。
- 断线、重复状态、切换战斗和新开一局时，不会制造假的受伤记录。
- 不同角色保持各自说话风格，未知角色使用普通风格。
- 没有新内容时可以少说或不说，不强行补台词。
- 模型失败、返回格式错误或内容重复时，不显示错误台词。

## 通过标准

- 生存相关台词与真实生命变化一致。
- 不误报伤害来源，不重复刷同一话题。
- 切换场景后不显示上一场战斗的旧台词。
