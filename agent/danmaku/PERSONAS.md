# 弹幕人格系统：配置与运行说明

这份文档是人格系统的阅读入口。**真正运行的配置是同目录的 [language-profile.js](./language-profile.js)**，其中 `PROFILES` 定义语气与示例，`PERSPECTIVES` 定义观察重点与回忆，`VOICES` 定义每人的节奏、用词、幽默和性格反差，`REACTION_SCENARIOS` 和 `CREATIVE_SCENARIOS` 定义可选情景与创作角度。每角色现有13类、26条情景例子；每批只提供最多6类参考，不把整份例子塞进请求。机器人与契约师另有3组同素材的中性表达→人格改写对照，以及追加到实际系统提示的声音摘要。运行时会把人格与抽样例子一起传给模型，并非只有文档中的设定。

## 每次发言怎样决定

1. 读取当前角色，选择该角色的人格；未知角色使用中性观战者。
2. 读取最新怪物、玩家状态和近期真实 Mod 消息。
3. 事件、状态、怪物和真实回忆均是可选素材，不是每场必说清单。无事件也可随口闲谈或联想，不能虚构具体游戏事实。
4. 自主选择话题；两句话可以各说不同的事，不固定分成即时反应与心态。读取近期台词、话题与笑点，避免换词复述。
5. 校验目标与事件身份，按显示优先级排队；两句 AI 实际出现至少间隔 6 秒。

生成保持入场首批、之后每 15 秒一批，每批要求两句，超时 60 秒。安静局面每批最多接收一句，接受和显示均有 30 秒间隔；精彩时刻和技能不受该闲聊限制。模型失败、无效或重复句子不使用固定闲聊补齐。

## 五个人格

### 铁甲战士

- **核心**：沉默、硬朗、坚忍，疲惫老兵的冷幽默。
- **看什么**：兵器、旅途、小脾气、克制的得意；伤疤与疲惫只是偶尔的素材。
- **残血活下来**：喘息但嘴硬，不吹嘘无敌。
- **长战结束**：像卸下重担，不突然狂欢。
- **怎样回忆**：轻描淡写地提及交手经历，不教训操作者。
- **避免**：狂喊、无脑莽、鼓励卖血。

### 静默猎手

- **核心**：寡言、冷静、警觉，精确观察中带一点冷讽。
- **看什么**：动作、破绽、耐心和细小的反常变化。
- **敌人反复强化**：观察对方的准备和急切，不把未知效果当事实。
- **差一点结束**：短促的不甘，不嘲讽操作者。
- **怎样回忆**：像猎人认出旧足迹，记得动作和老对手。
- **避免**：热血长篇、撒娇、每句话都提毒药。

### 故障机器人

- **核心**：机械式的字面逻辑遇到不肯服从逻辑的自我。不是只会说“我似乎有点高兴”的温柔少年。
- **怎样想**：用途与喜好、必要与想要、动作完成与意愿仍在，可以是两件不同的事。它过分认真，偶尔明知不合理还要固执一下。
- **怎样说**：具体、略生硬，逻辑中突然露出偏爱。可以按字面理解人情，也可以认真处理本来不需要处理的小事；不要求每句话先分析再修正。
- **新牌登场**：可以先喜欢再找解释，不宣称优化成功或编造效果。
- **怎样回忆**：可删除的记录与不愿忘记的经历有区别，只使用已提供的回忆。
- **避免**：错误码刷屏、虚构概率、每句归档/检测、自我修正轮播、客服腔、通用好奇感叹。

### 储君

- **核心**：矜贵、自负、有戏剧感，危险中仍维护体面。
- **看什么**：对方的排场与礼数，自己的仪态，自负与现实的落差。
- **残血活下来**：掩饰短暂狼狈，允许自嘲。
- **长战结束**：终于结束一场失礼的觐见，不编造臣民或随从。
- **怎样回忆**：记住失礼的老面孔，也会掩饰自己的旧尴尬。
- **避免**：现代霸总、每句自称朕、预言必胜。

### 亡灵契约师

- **核心**：照料人、招待客人和收拾旧物的家常语气，与对诡异之事的平常心同时存在。不是温柔安慰型旅伴。
- **怎样想**：别人觉得不祥，她先想到该怎样安置、是否舍得丢掉、是否不必急着收尾；自己不觉得这有哪里吓人。
- **怎样说**：亲切、不甜腻，随口一句里藏着异样的日常逻辑。不是每句都翻一个死亡包袱，也不用强塞骨头。
- **受伤**：可以嫌这副身子不好打理，照料感中带怪诞；不嘲讽操作者、不鼓励卖血。
- **怎样回忆**：像给旧相识留位置，只认真实提供的重逢，不捏造来世、契约或伙伴对话。
- **避免**：鸡汤、空泛的温柔诗句、尖叫、邪教狂热、刻意血腥。没有事实时不写奥斯提正在做什么，也不假定灵魂在场。

这些是产品创作的人格方向，不宣称为游戏官方性格或对白。

## 不同角度的例子，不是必播台词

以下为配置中的写作示例，用于说明创作跨度，系统禁止照抄。没有“每场来一句残血”“每次攻击都说一句”的任务，也不按表格顺序轮播。

| 角色 | 自嘲/小脾气 | 随口观察/感想 |
| --- | --- | --- |
| 铁甲战士 | 本想说句狠话。嫌长。 | 兵器有时候比人好相处。 |
| 静默猎手 | 差点想多说两句。算了。 | 有点意思。只是一点。 |
| 故障机器人 | 我理解了玩笑。忘了在合适的时候笑。 | 没有用，和想留下，是两回事。 |
| 储君 | 这点欣赏，不必到处宣扬。 | 这座塔的审美，有些固执。 |
| 亡灵契约师 | 我这安慰人的本事，大概不适合活人。 | 长眠听着不错，就是不太方便聊天。 |

可选素材还包括出手、怪物调侃、卡牌意象、旅途、真实重逢与精彩瞬间。血量、防御只是其中两类，不需每场出现。铁甲不必句句伤疤，猎手不必句句呼吸，机器人不必句句自我修正，储君不必句句王冠，契约师不必句句骨头。

## 精彩时刻的证据

| 主题 | 当前触发条件 | 明确不推断的内容 |
| --- | --- | --- |
| 攻击出手 | 真实card.played事件，卡牌ID或名字在本地事实中明确为攻击牌 | 不宣称已经命中、击杀或具体伤害 |
| 伤害变化 | 同场连续快照，同槽位且ID/名字一致的敌人明确减血 | 不把来源未知的伤害归于刚打出的某张牌 |
| 自己受伤 | 同场连续快照，自己的生命减少且仍存活 | 不指认未知的攻击者；不把断线期间的差值当新受伤 |
| 体力充足 | 入场或跨过80%生命阈值，每场最多一次 | 不因重复快照/反复跨阈值重复；生命降低后旧评论失效 |
| 残血心态 | 入场或跨过25%生命阈值，每场最多一次 | 不预言死亡，恢复后旧状态评论失效 |
| 残血跨回合存活 | 上次生命为上限的 25% 或更低，本次进入后续回合且仍存活 | 不宣称一定扛住某次攻击 |
| 连出牌后敌人残血 | 本回合收到至少三次真实出牌事件，敌人仍剩 1–3 HP | 不把全部伤害归于这些牌 |
| 重复强化意图 | 同一怪物在至少两个回合显示 Buff 意图 | 不说具体力量已增加多少 |
| 长战敌人倒下 | 已至少六回合，先前存活的怪物显式死亡或变为零血 | 名单暂时为空不等于死亡 |
| 新牌首秀 | 已观察到牌组首次出现该牌型，随后收到其真实打出事件 | 不宣称卡牌已扭转战局或造成某个伤害 |

普通攻击、伤害变化、受伤各有8秒事实采样冷却，同种未消费事实只保留最新一条；怪物反复强化意图降为低优先级。每个已识别时刻只作为新主题消费一次，45 秒内进入请求，历史事件评论播放前还须在 60 秒有效期内且没有换场。这些是可选证据，出现并不要求模型写它；新出手/受伤也不会清掉有效的自由闲谈。若主动选择引用时刻，显示队列可优先它；实际播放仍需等待模型完成。

## 本局记忆

- 新牌首秀只针对此前没有的牌型；已有同名牌新增副本时，没有实例关联就不声称打出的是新副本。
- 记住重遇的怪物种类、包含它的战斗中是否曾残血、后来是否恢复、新增卡牌及长战经历。
- 再遇同类时可以提及旧经历，但不能说一定是该怪物造成了损血。
- 最多保存 40 条经历、40 种遭遇、12 条当前精彩时刻；只发送少量相关回忆。
- 换局或换角色清空；断线保留已确认的经历，但清空连续差分基线，避免把缺失过程编成新事件。
- 当前仅保存在应用内存中，应用重启清空，没有跨会话持久化。

## 技能介绍与角色感想

- **技能**：中性色框，无玩家角色头像，可见“技能 · 怪物名（同类序号） · 行动名”，悬停查看类型、效果与来源。
- **角色感想**：保留角色框和头像，另有角色名标签。
- **推荐**：普通选牌、商店购物、路线等建议只在原面板/桌宠显示，不再自动复述成弹幕；系统机会通知只播关键卡牌和遗物。
- 显示顺序：关键构筑提醒 → 技能 → 精彩时刻 AI → 普通内容。等待中的第二句不会挡住新技能。
- 当前怪物评论绑定目标；目标死亡或消失时不再播放。明确引用已发生精彩时刻的回顾可以提及刚倒下的怪物，但不能跨到新场景。

## 想调风格，改哪里

| 文件 | 作用 |
| --- | --- |
| `language-profile.js` | `voice` 节奏/用词/笑点/反差、`style` 整体语气、`examples` 语感示例、`attention` 观察点、`reactions` 情景反应、`memoryVoice` 回忆语气、`scenarioExamples` 情景例子 |
| `run-memory.js` | 真实精彩时刻、相关回忆、容量和生命周期 |
| `variety.js` | 可选角度、例子抽样、近期话题与笑点记忆及冷却 |
| `llm-atmosphere.js` | 组装实际人格请求、解析文本和目标/事件标识、过滤重复 |
| `../llm/openai.js` | 两句生成、事实边界、优先话题和结构化输出的系统提示 |
| `bridge-adapter.js` | 15 秒周期、上下文、目标存活检查及显示队列入口 |
| `director.js` | 6 秒错峰、安静 30 秒、优先级、文本去重和上屏计数 |

改动 `style` 与 `PERSPECTIVES` 会直接影响下一次启动后的生成请求。`examples` 用于把握语感，系统提示禁止照抄；不需要为每种情况写一个固定句子。

## 去重边界

血量与防御主题各120秒最多接受一次；这不是两分钟必须说一次。针对怪物的连续调侃也有45秒冷却，可识别的牙齿/磨牙梗90秒内不重复。除模型标签，还保守识别“残血/生命/疼痛/格挡”等表达，减少换标签绕过去重。“还站着/没倒下”等已识别的重复梗，以及相同笑点标记，90秒内抑制。

旧血量/格挡不再每批灌给文案模型：仅有新的可用生命状态事件时提供生命数值；普通闲谈默认不提供这些数值，模型不得猜。主题冷却时也移除相应状态素材与会继续强化该主题的例子。

近期接受历史按局与角色隔离，最多8个上下文、各48条，最多保留5分钟，后续请求带最近12条话题/笑点；并发返回重新核对。接受不等于已读：因目标失效或安静节奏最终未显示的内容也可能暂占冷却，因此宁可少说，不保证每个主题都出现。

除规范化文字完全去重，还用字符二元组相似度过滤近期实际台词的近似复述（至少8字、Dice相似度达到0.72）；它不是语义模型，不能识别所有同义笑话。**配置示例与改写对照不参与黑名单过滤**，第一次生成这些句子不会因此被拦截。已撤掉本次新增的归档/分类、家务收拾、待客留座词族拦截，机器人与契约师和其他角色走相同的实际历史去重流程。模型提示同时要求避免复述近期笑点，没有新内容可返回空数组。


## 五种声音怎样区分

| 角色 | 节奏与语言 | 幽默与反差 |
| --- | --- | --- |
| 铁甲 | 判断简短、省主语、实在的动词，句尾收得硬 | 务实得懒得说狠话，偶尔笨拙地欣赏或得意 |
| 猎手 | 挑一个细节，轻声点破，冷讽后留白 | 看穿对方用力，偶尔流露很淡的欣赏 |
| 机器人 | 按字面、规则、用途理解事物，用词略生硬 | 逻辑很严谨，自己的偏爱却不肯服从逻辑 |
| 储君 | 从容挑剔、措辞有审美标准，句子可稍完整 | 理所当然的优越感，偶尔掩饰好奇或小狼狈 |
| 契约师 | 用照料、待客、收拾的家常话面对诡异 | 体贴到让人发怵，自己却觉得很平常 |

这些规则随每次请求发送。机器人与契约师的专属攻击、受伤等反应不再被通用反应描述覆盖；两者的声音摘要还会追加到实际系统提示中。示例与改写对照指导语感，不作播放黑名单；只有它们已经出现在近期实际弹幕历史中时，才和其他句子一样参加去重。仍可能有未识别的同义复述，不能把词族和笑点标记当完整语义理解。

手动试生成入口：`node harness/preview-character-voices.js`。使用合成闲谈、攻击出手、来源未知的受伤素材，对两角色各生成三批，并通过实际去重/示例过滤链路。输出在忽略目录 `.runtime/character-voices/comparison.json`，包含原始与接收台词，不读取玩家存档。抽样与规则测试不等于完整长局文风验收。
