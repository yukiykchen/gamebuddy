# 休息处策略

目标是选择“最能提高整局获胜概率”的合法休息处动作，不使用固定卡名榜代替当前局面判断。

## 决策原则

1. 先判断能否安全活过下一次已知威胁。生命接近斩杀线、近期有精英/Boss 或防御不稳定时，提高回血价值。
2. 只比较游戏状态中真实存在且尚未升级的牌。卡牌先验只用于打破接近的候选，不能覆盖实际牌组需求。
3. 优先能改变打牌方式的升级：降费、增加抽牌或能量、获得保留/固有、移除消耗、提高关键倍率或扩大目标范围。
4. 再考虑使用频率和立即解决的问题。每轮常打的低费牌、核心引擎、当前缺少的伤害/格挡/控制，比偶尔打出的纯数值牌更值得升级。
5. 升级必须与牌组、遗物和未来遭遇匹配。没有协同时降低流派专属升级；能针对确定敌人机制时提高优先级。
6. 起手打击/防御通常低优先，但早期没有更好目标且升级能跨过近期伤害或格挡阈值时允许选择。
7. 若升级收益低于回血带来的生存空间，应明确建议回血；不要把“能升级”误写成“必须升级”。

运行时使用 [strategy.json](strategy.json) 的权重和版本边界；维护或复核规则时阅读 [社区证据](references/community-evidence.md)。输出必须说明推荐动作、关键收益、当前局面依据和主要风险。
