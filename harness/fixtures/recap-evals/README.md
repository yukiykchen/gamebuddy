# 单局复盘合成评测数据

这里的 10 份 JSON 均由 `generate-recap-evals.js` 确定性生成，每份包含 157–217 个 `gamebuddy.fact-event.v1` 事件，`manifest.json` 列出逐份数量。它们是**人工构造的边界样本**，不是《杀戮尖塔 2》实机采集结果，也不是玩家真实战绩。

卡牌和敌人标识取自仓库随附的《杀戮尖塔 2》卡牌、怪物目录，场景围绕铁甲战士、普通战斗、火堆升级和精英战。事件序列用于检验身份、覆盖、SL、伤害与文案边界；目录版本、Hook 时点和动态机制仍需 Windows 实机验收。

每份 `expected.candidate` 是待检查片段，`expected.allowed` 表示该片段是否应发布；`expected.forbidden` 列出不得臆断的句子。对照样本包括未抽到/抽到但能量不足、同名副本、自动打出、真实结算/仅请求伤害、获得格挡/实际抗伤、重载观察和采集缺口。

代码评测入口为 `review/recap/recap.test.js`。本次变更仅创建数据与评测代码；合成样本通过不代表真实对局的故事质量或游戏版本兼容性通过。
